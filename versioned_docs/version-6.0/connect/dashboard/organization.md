# Organization

### Information

<figure><img src="../../.gitbook/assets/info.png" alt=""><figcaption></figcaption></figure>

This section allows users to view and edit institutional information about the company or organization. These details are used in official documents, quotations, internal reports, and automated communications.

* Organization Name
* Full Physical Address
* Contact Details

### Corporate Logo

<figure><img src="../../.gitbook/assets/logo.png" alt=""><figcaption></figcaption></figure>

This section allows you to **upload your organization’s logo**, which will be automatically included in generated documents such as **quotations, reports, invoices, and internal communications**.

:::info
_Use a **high-resolution, transparent background** logo (preferably in SVG or PNG format) to ensure the best quality across all outputs._
:::

#### Functionality

* All fields are editable by users with `Owner` role.
* Changes must be confirmed using the **Save** button.
