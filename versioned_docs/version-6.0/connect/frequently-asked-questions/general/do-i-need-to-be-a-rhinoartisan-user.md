# Do I need to be a RhinoArtisan user?

No, not at all! RhinoArtisan Connect is open to everyone. You don’t need to own RhinoArtisan or be a previous user to create an account and start using all the core features.

However, RhinoArtisan users have access to additional features inside RhinoArtisan, such as customizers, direct publishing to Connect, and other productivity advantages integrated into the software.
