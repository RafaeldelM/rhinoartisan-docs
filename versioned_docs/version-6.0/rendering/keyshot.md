# Keyshot

**KeyShot Render** is a powerful 3D rendering software known for its ease of use and ability to produce high-quality photorealistic images. It is widely used in various industries, such as product design, architecture, jewellery and medical visualization.

**Key features:**

* **Fast rendering:** KeyShot offers exceptional rendering speed, allowing you to get results quickly and make iterative design changes.
* **Realistic materials and textures:** The software features a vast library of predefined materials and textures and the ability to create custom materials for authentic results.
* **Advanced lighting:** KeyShot offers various lighting options, including point lights, area lights, global illumination, and predefined lighting environments.
* **CAD integration:** It can be easily integrated with CAD programs like SolidWorks, Autodesk Inventor, and Rhino, facilitating the workflow from design to visualization.
* **Animations:** KeyShot allows you to create animations and image sequences to showcase the movement and interaction of objects.
* **Post-production:** The software includes basic post-production tools for adjusting exposure, contrast, saturation, and other image parameters.

:::info
To integrate, you must install a free KeyShot plugin. Below, we show you how to download and install it.
:::

### <img src="../.gitbook/assets/G2_01_RENDERING_KEYSHOOT.png" alt="" data-size="line"> Keyshot: Live Linking

One of the standout features is "Live Linking." With Live Linking, you can make changes to your model in Rhino, and those changes will automatically update in KeyShot without needing to re-import the model. This feature is handy during the design iteration process.

### <img src="../.gitbook/assets/G2_02_RENDERING_KEYSHOOT_UPDATE.png" alt="" data-size="line"> Keyshot: Update

Once you've made your changes in RhinoArtisan, instead of re-exporting the entire model, you click the Update button in the KeyShot plugin. This only updates KeyShot, keeping your work synchronized between the two programs.

### <img src="../.gitbook/assets/G2_03_RENDERING_KEYSHOOT_EXPORT.png" alt="" data-size="line"> Keyshot: Export

The plugin provides a "Render" button within RhinoArtisan, enabling you to send your 3D models directly to KeyShot without manual exporting and importing. This makes it easier and faster to start rendering.

### How do you install the KeyShot plugin for RhinoArtisan?

&#x20;It’s straightforward; we’ll use the package manager for this. &#x20;

1. Execute the command PackageManager, and type in the search field: **keyshot**

<figure><img src="../.gitbook/assets/image (560).png" alt=""><figcaption><p>Rhino Package Manager</p></figcaption></figure>

2. Select Keyshot Studio and click on the **Install** button:

<figure><img src="../.gitbook/assets/image (558).png" alt=""><figcaption><p>Rhino Package Manager and Keyshot</p></figcaption></figure>

3. A new window will request that you click the **Install** button to download and install it.
