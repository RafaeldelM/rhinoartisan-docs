# Refresh All Textures

## <img src="../../../.gitbook/assets/G6_08_RENDERING_REFRESH_ALL_TEXTURES.png" alt="" data-size="line"> Refresh All Textures

The RefreshAllTextures command reloads the texture files from disk and refreshes displays that are currently using the textures.

For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/refreshalltextures.htm?Highlight=RefreshAllTextures%20).
