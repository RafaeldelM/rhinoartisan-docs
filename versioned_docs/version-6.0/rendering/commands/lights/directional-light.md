# Directional Light

### <img src="../../../.gitbook/assets/SPOTLIGHT_02_RENDERING_DIRECTIONAL_LIGHT (1).png" alt="" data-size="line"> Directional Light

The DirectionalLight command inserts a light that simulates the sun defined with parallel rays and a direction.

<figure><img src="../../../.gitbook/assets/directionallight-001.png" alt=""><figcaption></figcaption></figure>

**Steps**

1. Pick a location at which to aim the directional light.
2. Pick a location for the directional light.



For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/lights.htm#DirectionalLight).
