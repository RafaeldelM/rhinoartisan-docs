# 3D Print



## <img src="../../.gitbook/assets/FILE_3DPRINT_PRINT (1).png" alt="" data-size="line"> 3D Print

The **3D Print** command sends the arranged designs directly to the 3D printer management software configured in your system. RhinoArtisan comes preconfigured with several of the most common 3D printers, but it also allows you to install and use the management software of any printer you prefer.

The preset printers are the following :&#x20;

### <img src="../../.gitbook/assets/15_3DPRINT_ASIGA (2).png" alt="" data-size="line"> Asiga Composer Connector

With this command, you can open this design in Asiga's slicer software, Composer.

Once you run this command, the slicer software will open with your design.

### <img src="../../.gitbook/assets/16_3DPRINT_FORMLABS (1).png" alt="" data-size="line">Formlabs Preform Connector

With this command, you can open this design in Formlabs slicer software, Preform. Once you run this command, the slicer software will open with your design.

### <img src="../../.gitbook/assets/17_3DPRINT_3DSYSTEM (1).png" alt="" data-size="line"> 3D Systems Geomagic Connector

With this command, you can open this design in 3D Systems' slicer software, Geomagic. Once you run this command, the slicer software will open with your design.

### ​<img src="../../.gitbook/assets/18_3DPRINT_ANYCUBIC (1).png" alt="" data-size="line"> Anycubic Workshop Connector <a href="#anycubic-workshop-connector" id="anycubic-workshop-connector"></a>

With this command, you can open this design in Anycubic's slicer software, Anycubic Workshop. Once you run this command, the slicer software will open with your design.

### ​<img src="../../.gitbook/assets/B9 captative.png" alt="" data-size="line"> B9 Captivate Connector <a href="#b9-captivavate-connector" id="b9-captivavate-connector"></a>

With this command, you can open this design in B9's slicer software, Captivate.

Once you run this command, the slicer software will open with your design.

### ​<img src="../../.gitbook/assets/Elegoo (1).png" alt="" data-size="line"> Elegoo **Chitubox** Connector <a href="#elegoo-cura-connector" id="elegoo-cura-connector"></a>

This command opens this design in the **Chitubox**slicer software. It is ideal to have an Elegoo 3D printer or one from another brand.

Once you run this command, the slicer software will open with your design.

**Benefits**

* Simplifies the printing process by integrating with preconfigured printer options.
* Offers flexibility to work with any 3D printer software.
* Reduces setup time and ensures a smooth workflow for 3D printing.
