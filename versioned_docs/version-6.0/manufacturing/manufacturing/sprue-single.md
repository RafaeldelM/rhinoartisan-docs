# Sprue Single



## <img src="../../.gitbook/assets/3DPRINTING_SPRUE_SINGLE.png" alt="" data-size="line"> Sprue Single

The **Sprue Single** command places a sprue at a specified point on the mesh, allowing customization of its shape and dimensions.

1. **Point Selection**
   * The user is prompted to select the exact point on the mesh where the sprue will be placed.
2. **Parameter Configuration**
   * **Height:** Adjusts the length of the sprue.
   * **X and Y Axes:** Defines the diameters of the ellipse at the top and bottom of the sprue.
   * **Shape:** Allows the creation of either round sprues (with a consistent diameter) or conical sprues (with variations between the top and bottom ellipses).
3. **Applications**\
   This command is ideal for designing customized sprues tailored to specific casting production needs.
