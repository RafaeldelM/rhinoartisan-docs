# Thickness

## <img src="../../.gitbook/assets/ANALYZE_ANALYZE_THICKNESS (1).png" alt="" data-size="line"> Thickness

The **Thickness** command allows you to measure the thickness of an object at any point on its surface, providing precise and visual information about its thickness.

1. **Object Selection**\
   When the command is activated, you are prompted to select the object for thickness measurement.
2. **Thickness Measurement**\
   Once the object is selected, you can measure the thickness at any point on its surface.
   * As you move the cursor over the surface, the command automatically calculates the thickness from the selected point in the direction of its **normal**.
   * A visual line is displayed, indicating the direction of the normal and the path used for the measurement.
3. **Thickness Marking**\
   At the desired point, clicking the mouse will place a text marker in the viewport showing the thickness measurement at that location. This allows you to record thickness values at multiple points on the object for future reference.
