# Global Thickness

## <img src="../../.gitbook/assets/ANALYZE_ANALYZE_GLOBAL_THICKNESS.png" alt="" data-size="line"> Global Thickness

The **Global Thickness** command analyzes the thickness of an object and visually highlights areas that meet or fail to meet a specified minimum thickness.

1. **Minimum Thickness Setting**\
   When the command is activated, the user is prompted to specify the desired minimum thickness through the command line. The default minimum thickbess is set to 0.6 mm.
2. **Visualization of Results**
   * **Green:** Represents areas that exceed the specified minimum thickness.
   * **Red:** Indicates areas that are below the minimum thickness.
3. **Mesh Options**\
   In the command line, users can choose whether to keep or discard the mesh generated during the analysis.
