# Identifyer

## <img src="../../.gitbook/assets/3DPRINTING_DESIGNS_IDENTIFIER.png" alt="" data-size="line"> Identifyer

The **Identifyer** command allows you to create a custom label to identify a ring, with configurable text and a connecting cylindrical rod.

1. **Text Configuration**
   * Enter the desired text for the label in the command panel.
   * Adjust the text size to fit your design.
2. **Cylinder Configuration**
   * Specify the thickness of the cylinder connecting the label to the ring's interior.
   * Define the start and end points of the cylinder to avoid intersections with critical design features, such as holes or engravings.
3. **Applications**\
   This command is particularly useful for identifying and differentiating rings of the same model with varying sizes, ensuring clear organization in the design process.
