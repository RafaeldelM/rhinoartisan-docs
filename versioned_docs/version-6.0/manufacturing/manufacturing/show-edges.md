# Show Edges

## <img src="../../.gitbook/assets/ANALYZE_SHOW_EDGES.png" alt="" data-size="line"> Show Edges&#x20;



The **ShowEdges** command highlights specific edge types on selected objects, helping diagnose and troubleshoot geometry issues.

1. **Edge Types Displayed:**
   * **All Edges:** Shows all edges of surfaces, polysurfaces, meshes, and SubD objects.
   * **Naked Edges:** Highlights edges not connected to another, indicating openings.
   * **Non-Manifold Edges:** Displays edges shared by more than two faces, often causing modeling issues.
2. **Additional Features:**
   * Visualizes selected edges with highlighted lines and endpoint markers.
   * Zoom options to focus on all edges or specific ones sequentially.
   * Mark edges with points for persistent references.
   * Customize edge display colors.
