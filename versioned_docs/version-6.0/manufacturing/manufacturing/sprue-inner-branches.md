# Sprue Inner Branches

## <img src="../../.gitbook/assets/3DPRINTING_INNER_BRANCHES.png" alt="" data-size="line"> Sprue Inner Branches

The **Sprue Inner Branches** command is especially useful for rings with holes on the inside or delicate and intricate structures, such as Full Eternity bands. This command helps create internal branches that support the structure and ensure proper metal flow during the casting process.



<figure><img src="../../.gitbook/assets/image (141).png" alt=""><figcaption></figcaption></figure>

#### **Command Structure**

**Selection Panel**

* **Mesh Selection**: In this panel, you select the mesh of the object to which you want to apply the **Sprue Inner Branches**.
* **Branch Growth Point Button**: A button to specify the starting point from which the branches will grow. Typically, this is at the center of the ring, but you can choose a different point if needed.

**Parameters Panel**

1. **Branch Starting Point (Height)**:
   * Allows you to define the **height** from which the branches will start, in case you prefer to begin at a point other than the center of the ring.
2. **Add Branches**:
   * This button allows you to select the endpoint of the branches. You can define where the branches will end by choosing appropriate contact areas within the design.
3. **Delete Branches**:
   * A buttons is available to delete the branches all the branches.
   * To delete a specific branch, hold down the **Shift** key and click on the branch's gumball. This action will immediately remove the selected branch.
4. **Diameter Settings**:
   * You can define the **starting diameter** of the branches and the **diameter at the contact point** with the mesh, ensuring the branches are appropriately sized for support and metal flow.
5.  **Symmetry Option**:

    * A symmetry option allows you to quickly create mirrored branches, making it easier to design symmetrical structures.

    <figure><img src="../../.gitbook/assets/image (142).png" alt="" width="268"><figcaption></figcaption></figure>

    #### **Workflow**

    * Select the mesh of the object you want to apply the command to.
    * Specify the point from which the branches will grow, typically from the center of the ring, or a different height.
    * Set the diameters at the starting point and the contact point of the branches.
    * Use the **Add Branches** button to select where the branches will end, ensuring they connect to flat or smooth areas to avoid crucial design features or holes.
    * Delete any unnecessary branches using the delete buttons.
    * Enable the symmetry option if your design is symmetrical to streamline the process.

    This command is ideal for creating internal branches in rings with intricate structures, ensuring proper support and flow during casting while maintaining the integrity of delicate designs.
