# Does RhinoArtisan include Rhino?

We offer two versions of RhinoArtisan: **RhinoArtisan 6.0 Full Edition**, which includes Rhino, and **RhinoArtisan 6.0 for Rhino Users**, perfect for those who already have Rhino. For more information and pricing, please visit [www.rhinoartisan.com/buy](http://www.rhinoartisan.com/buy).

:::info
RhinoArtisan works on Rhino 8.0 for Windows. [More details...](../../getting-started/system-requirements.md)
:::
