# Report

## <img src="../../.gitbook/assets/01_DRAFTING_REPORT.png" alt="" data-size="line"> Report

With this command, you can create a full Report sheet containing four viewports, its name, and other details.

![](/img/v60/Report.jpg)

After running this command, a new Layout will be created with four viewports arranged to fit the squares on your new Report sheet. You can double-click on any viewport to change its visualization mode, angle, and zoom.

All texts can be edited by double-clicking on them. Using the **Add logo** command, you can use your logo instead of the default 2Shapes one shown in the lower-left corner.
