# Make 2D

## <img src="../../.gitbook/assets/22_DRAFTING_MAKE_2D_DRAWING.png" alt="" data-size="line"> Make 2D

The Make2D command draws object edges and outlines in one or four views as flat curves on the World Top plane.

<div align="left"><figure><img src="../../.gitbook/assets/Make2d.jpg" alt=""><figcaption><p>Make2D Example</p></figcaption></figure></div>

#### Steps

1. Select the objects
2. Specify the layout and object visibility options

For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/make2d.htm).
