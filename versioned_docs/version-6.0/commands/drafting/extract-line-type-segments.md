# Extract Line Type Segments

## <img src="../../.gitbook/assets/25_DRAFTING_EXTRACT_LINE_TYPE_SEGMENTS.png" alt="" data-size="line"> Extract Line Type Segments

The ExtractLineTypeSegments command converts line type patterns of the selected curves to curve segments and points.
