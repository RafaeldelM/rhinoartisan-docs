#### **Breakdown Gems**

When activating the **Breakdown Gems** command, it generates a text output that can be placed anywhere in the **viewport**, displaying the gemstone details contained in the **Breakdown Details**.

<figure><img src="../../.gitbook/assets/image (733).png" alt=""><figcaption></figcaption></figure>

**Advantages:**

* Instantly displays gemstone details in the viewport.
* Allows flexible placement of information within the design.
* **Precise classification** – Displays an exact breakdown of gemstones by type, size, and quantity.
* Speeds up workflow by eliminating manual calculations.
