# Breakdown Processes

### <img src="../../.gitbook/assets/BREAKDOWN_PROCESSES.png" alt="" data-size="line"> **Breakdown Processes**

:::info
Available in the 6.2 update
:::

When activating the **Breakdown Processes** command, it generates a text output that can be placed anywhere in the **viewport**, displaying the process details contained in the **Breakdown Details**.

<figure><img src="../../.gitbook/assets/image (734).png" alt=""><figcaption></figcaption></figure>



**Advantages:**

* Instantly displays process details in the viewport.
* Ensures accuracy by following the **Outliner** configuration.
* Allows flexible placement of information within the design.
* Speeds up workflow by eliminating manual documentation.
