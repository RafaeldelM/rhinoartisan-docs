# Add Logo

## <img src="../../.gitbook/assets/07_DRAFTING_ADD_LGO (1).png" alt="" data-size="line"> Add Logo

This command allows us to add our logo to the [Report ](report.md)command. As shown in the image below, the default logo is from 2Shapes, but we recommend adding your own.

<figure><img src="../../.gitbook/assets/Add My Logo.jpg" alt=""><figcaption></figcaption></figure>

Once you have run this command, you will be asked to select which objects you want to use as a logo. These objects will be saved in your User Folder.

The ideal logo format is vectorial, such as SVG or Illustrator. If you don’t have a logo in these formats, you can create one from scratch, draw it directly, or vectorize an image using [raster-to-vector](../curve/raster-to-vector.md) command.
