# Generate Dimension from Bangle

<img src="../../.gitbook/assets/DRAFTING_GENERATE_DIMENSIONS_BANGLE.png" alt="" data-size="line"> **Generate Dimensions from Bangle** is a one-click tool that extracts and displays the main dimensions of any bangle.&#x20;

It automatically detects and displays:

* The **width and length** of the **top, bottom, and side sections**
* The **height and length** of the **inner ellipse**
