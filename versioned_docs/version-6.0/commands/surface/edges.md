# Edges

## <img src="../../.gitbook/assets/G2_04_SURFACE_EDGES.png" alt="" data-size="line"> Edges

The EdgeSrf command creates a surface from two, three, or four selected curves.

### Steps

[Select](https://docs.mcneel.com/rhino/8/help/en-us/popup_actions/select_objects.htm) the curves, and press [Enter](https://docs.mcneel.com/rhino/8/help/en-us/popup_actions/enter_key.htm).

For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/edgesrf.htm).

### Tips

* You can use surface edges as the curves for a new surface.
* For a surface from closed planar curves, use the [PlanarSrf](from-planar-curves.md) command.



For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/edgesrf.htm#\(null\)).
