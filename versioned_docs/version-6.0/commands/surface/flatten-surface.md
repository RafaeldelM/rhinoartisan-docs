# Flatten Surface

## <img src="../../.gitbook/assets/G5_10_SURFACE_ADVANCED_FLATTEN.png" alt="" data-size="line"> Flatten Surface

The FlattenSrf command flattens surface edges onto the construction plane to create planar curves.

**Steps**

1. Select a surface edge.
2. Select another edge.\
   Type a number for the sample point spacing.



For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/flattensrf.htm#\(null\)).
