# Convert to Single Spans

## <img src="../../.gitbook/assets/G5_07_SURFACE_CONVERT_TO_SIMPLE_SPANS.png" alt="" data-size="line"> Convert to Single Spans

The ConvertToSingleSpans command splits a NURBS surface at knots to create untrimmed single-span surfaces.

<div align="left"><figure><img src="../../.gitbook/assets/converttosinglespans.gif" alt=""><figcaption></figcaption></figure></div>

### Command-line options

**DeleteInput**: Deletes (Yes) or keeps (No) the input objects.

**Direction**: Specifies to split the surface in the U, V, or Both directions.



For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/converttosinglespans.htm#\(null\)).
