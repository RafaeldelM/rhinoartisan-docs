# Surface Tangent

## <img src="../../.gitbook/assets/G5_03_SURFACE_ADVANCED_TANGENT.png" alt="" data-size="line"> Surface Tangent

The SetSurfaceTangent command sets an untrimmed surface edge tangent direction.

**Steps**

1. Select an untrimmed surface edge.
2. Pick the base point for tangent direction.
3. Pick the second direction point.



For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/setsurfacetangent.htm#\(null\)).
