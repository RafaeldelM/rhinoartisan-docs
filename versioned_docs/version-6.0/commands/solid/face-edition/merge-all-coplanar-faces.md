# Merge All Coplanar Faces

<img src="../../../.gitbook/assets/G7_03_SOLID_MERGE_TWO_COPLANAR_FACES.png" alt="" data-size="line"> Merge All Coplanar Faces

The MergeAllCoplanarFaces command combines the faces of each planar region on a mesh, polysurface, or SubD into a single face.

<figure><img src="../../../.gitbook/assets/mergeallcoplanarfaces.gif" alt=""><figcaption></figcaption></figure>



For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/mergecoplanarface.htm#MergeAllCoplanarFaces).
