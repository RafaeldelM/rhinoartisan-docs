# SetPerFaceColorByFacePack

## <img src="../../../.gitbook/assets/G7_04_SUBD_SET_PER_FACE_COLOR_BY_FACE_PACK.png" alt="" data-size="line"> SetPerFaceColorByFacePack <a href="#profiles" id="profiles"></a>

The SetPerFaceColorByFacePack command changes colors of SubD faces based on the divisions of rectangular quad grids. It lets you preview how the ToNURBS command (Faces=Packed) converts a SubD to NURBS.

<div align="left"><img src="https://docs.mcneel.com/rhino/8/help/en-us/image/topic_illustrations/setperfacecolorbyfacepack.gif" alt=""></div>



For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/packsubdfaces.htm#SetPerFaceColorByFacePack).
