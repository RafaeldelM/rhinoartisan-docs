# Append

## <img src="../../../.gitbook/assets/G4_04_SUBD_APPEND.png" alt="" data-size="line"> Append

#### **Append**

#### Selects an existing mesh or SubD to which the new faces will be added.

* During appending new faces, press ESC to cancel the current face creation. Press ESC one more time to cancel the command.

For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/3dface.htm#Append).
