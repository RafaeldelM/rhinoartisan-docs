# InsertPoint

## <img src="../../../.gitbook/assets/G4_01_SUBD_INSERT_POINT_TO_MESH.png" alt="" data-size="line"> InsertPoint

The InsertPoint command adds vertices and edges to a Mesh or SubD along the picked points on edges.

### Input

* SubD / Mesh Edge

#### **Steps**

1. Select a mesh or SubD.
2. Pick points on edges.

<div align="left"><img src="https://docs.mcneel.com/rhino/8/help/en-us/image/topic_illustrations/insertpoint.gif" alt=""></div>

### Options

#### **Undo**

Removes the last picked point.



For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/insertpoint.htm#\(null\)).
