# RemoveCrease

## <img src="../../../.gitbook/assets/G5_02_SUBD_CREASE_REMOVE.png" alt="" data-size="line"> RemoveCrease

The RemoveCrease command smoothes creased SubD edges/vertices, or welds mesh edges.

![](https://docs.mcneel.com/rhino/8/help/en-us/image/topic_illustrations/removecrease.gif)

Remove creased edges on a SubD (left) and a mesh (right).

### Input

* SubD edges and vertices
* SubD control net edges and Points
* Mesh edges



For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/crease.htm#RemoveCrease).
