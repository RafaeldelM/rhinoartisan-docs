# Dup Mesh Hole Boundary

## <img src="../../../.gitbook/assets/DUP_MESH_HOLE_BOUNDARY.png" alt="" data-size="line"> Dup Mesh Hole Boundary <a href="#profiles" id="profiles"></a>

The `DupMeshHoleBoundary` command in Rhino duplicates the boundary of a mesh hole by creating a polyline around it. To use it, simply select the boundary of the hole in the mesh. This tool is helpful for creating clear, editable boundaries around mesh holes.&#x20;
