# Remove Crease

## <img src="../../../.gitbook/assets/CREASE.png" alt="" data-size="line"> Remove Crease <a href="#profiles" id="profiles"></a>

The RemoveCrease command smoothes creased SubD edges/vertices, or welds mesh edges.

<div align="left"><img src="https://docs.mcneel.com/rhino/8/help/en-us/image/topic_illustrations/removecrease.gif" alt=""></div>

Remove creased edges on a SubD (left) and a mesh (right).

### Input

* SubD edges and vertices
* SubD control net edges and Points
* Mesh edges
