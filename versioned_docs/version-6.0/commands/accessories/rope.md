# Rope

## <img src="../../.gitbook/assets/SMART_ROPE (1).png" alt="" data-size="line"> Rope <a href="#rope" id="rope"></a>

With this command, you can generate a rope running curves. It's advantageous to give a creative touch to any design you add this to or even achieve some sailor-themed style.

![](/img/v60/Rope.jpg)

We'll start by selecting one or more curves.

On its parameters, you can change the diameter of each thread, the whole rope width, the amount of thread, and the number of turns from start to finish. Also, if you have selected a closed curve, you can enable Infinite to make the rope seamless.

:::tip
This element is editable, meaning it can be modified anytime.
:::
