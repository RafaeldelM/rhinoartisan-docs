# Honeycomb

## <img src="../../.gitbook/assets/SMART_HONEY_COMB (1).png" alt="" data-size="line"> Honeycomb - Azure <a href="#honeycomb" id="honeycomb"></a>

With this command, you can select a closed curve, and 2Shapes will fill it with a Honeycomb pattern. It's beneficial for filling up hollowed designs and creating gorgeous geometric patterns as Azures.

![](/img/v60/Honeycomb.jpg)

After running this command, you can select the closed curve you want to use by clicking on the selection square. Below, you can find the parameters such as the honeycomb thickness, its height, and all its measurements.

:::info
Flow by Surface is an excellent tool for applying these shapes to any 3D surface.
:::
