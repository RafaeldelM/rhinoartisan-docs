# Link

## <img src="../../.gitbook/assets/ICON_LINK (1).png" alt="" data-size="line"> Link <a href="#link" id="link"></a>

The chain link command allows us to design a slab that precisely fits our taste and style. We define measures and rotations and analyse how they behave with the front and rear links. It also allows us to create a Cuban link in seconds, analyzing the weight in real-time for each modification.

<figure><img src="../../.gitbook/assets/Link (1).jpg" alt=""><figcaption></figcaption></figure>

The first four parameters refer to the dimensions of the link, such as height, width, etc. The last two parameters determine how the link interacts with adjacent links to enable boolean operations between them.
