# Bail

## <img src="../../.gitbook/assets/RIBOON_SMART_BAIL.png" alt="" data-size="line"> Bail <a href="#bail" id="bail"></a>

This command creates bail pieces, which are ideal for pendants and necklace designs.

As with many other RhinoArtisan commands, the style library will be displayed when the command is executed. We can start with a predefined one. We can edit it by clicking on the pencil to edit all the parameters in detail.

![](/img/v60/Bail.jpg)

On the parameters menu, you can define its shape and measurements for the top and lower sections, as well as enable or disable the O-ring that links to your main piece.

:::tip
This element is editable, meaning it can be modified anytime.
:::
