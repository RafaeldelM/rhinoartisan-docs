# Spiral

## <img src="../../.gitbook/assets/G1_10_DRAW_SPIRAL.png" alt="" data-size="line"> Spiral

The **Spiral** command in Rhino generates customizable spirals with various options for control. Users can define the **Turns** (number of revolutions), **Pitch** (distance between turns), **Start/End Radius** (size at the ends), and choose between **Flat** (2D) or **Vertical** (3D) configurations. The **Around Curve** option aligns the spiral to a selected curve for unique shapes. Jewelers can use this command to create intricate designs like twisted bands or filigree with precision and adaptability.
