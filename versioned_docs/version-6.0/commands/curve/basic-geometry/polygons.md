# Polygons

### <img src="../../../.gitbook/assets/G1_08_DRAW_POLYGON.png" alt="" data-size="line"> Polygon

The Polygon command draws a closed polyline with a specified number of sides

### <img src="../../../.gitbook/assets/POLYGON_01_DRAW_CIRCUMSCRIBED_CENTER_RADIUS.png" alt="" data-size="line"> Circumscribes Polygon

Draws the polygon where the midpoints of the sides touch an imaginary circle of a specified radius.

### <img src="../../../.gitbook/assets/POLYGON_02_DRAW_POLYGON_BY_EDGE.png" alt="" data-size="line"> Polygon: By Edge

Draws a polygon by defining one edge.

### <img src="../../../.gitbook/assets/POLYGON_03_DRAW_SQUARE_CORNER.png" alt="" data-size="line"> Square

The Square command draws a closed square polyline.

### <img src="../../../.gitbook/assets/POLYGON_04_DRAW_SQUARE_CIRCUMSCRIBED_CENTER_RADIUS.png" alt="" data-size="line"> Circumscribed Square

Draws the square polyline where the midpoints of the sides touch an imaginary circle of a specified radius.

### <img src="../../../.gitbook/assets/POLYGON_05_DRAW_SQUARE_EDGE.png" alt="" data-size="line"> Square: Edge

Draws a square polyline by defining one edge.

### <img src="../../../.gitbook/assets/POLYGON_06_DRAW_STAR.png" alt="" data-size="line"> Star

Draws a star-shaped polygon.
