# Rectangle

### <img src="../../../.gitbook/assets/G1_06_DRAW_RECTANGLE (1).png" alt="" data-size="line"> Rectangle

Draws the rectangle using two opposite corners.

### <img src="../../../.gitbook/assets/RECTANGLE_01_DRAW_CORNER (1).png" alt="" data-size="line"> Center, Corner

Draws the rectangle from the center point and a corner.

### <img src="../../../.gitbook/assets/RECTANGLE_02_DRAW_POINTS (1).png" alt="" data-size="line"> 3 Points

Draws the rectangle using two adjacent corner locations and a location on the opposite side.

### <img src="../../../.gitbook/assets/RECTANGLE_03_DRAW_ROUNDED (1).png" alt="" data-size="line"> Rounded Rectangle

Rounds the corners of the rectangle with arcs or conic sections.

### <img src="../../../.gitbook/assets/RECTANGLE_04_DRAW_VERTICAL_CPLANE (1).png" alt="" data-size="line"> Vertical

Draws the rectangle perpendicular to the construction plane.
