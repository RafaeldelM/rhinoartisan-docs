# Bend

### <img src="../../../../.gitbook/assets/G9_08_TRANSFORMATION_BEND.png" alt="" data-size="line"> Bend <a href="#profiles" id="profiles"></a>

The **Bend** command deforms objects by bending them along a defined spine arc. To use it, select the objects, set the start and end points of the spine line, and choose a point to bend through.

Command-line options:

* **Copy**: Creates a copy of the objects when bending.
* **Rigid**: Changes object positions without deforming them.
* **LimitToSpine**: Limits bending to the spine or allows bending beyond it.
* **Angle**: Sets the bend angle.
* **Symmetric**: Bends objects symmetrically around the center.
* **PreserveStructure**: Maintains the control-point structure of curves and surfaces for accuracy.
* **NonAttenuated**: Controls how the morph strength is applied along the bending arc.

These options provide flexibility for precise bending and deformation of objects.



For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/bend.htm#\(null\)).
