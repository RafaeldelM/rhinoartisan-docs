# Cage Release

### <img src="../../../.gitbook/assets/G10_06_TRANSFORMATION_CAGE_RELEASE.png" alt="" data-size="line"> Cage Release <a href="#profiles" id="profiles"></a>

The ReleaseFromCage command removes selected objects from the influence of a control object set up by the CageEdit command.



For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/cageedit.htm#ReleaseFromCage).
