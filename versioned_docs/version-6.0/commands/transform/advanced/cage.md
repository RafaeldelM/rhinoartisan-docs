# Cage

### <img src="../../../.gitbook/assets/G10_02_TRANSFORMATION_CAGE_CREATE.png" alt="" data-size="line"> Cage <a href="#profiles" id="profiles"></a>

The **Cage** command creates a box-shaped cage object that can be used with the **CageEdit** command to deform other objects. This technique is useful for achieving smooth deformations on complex objects by manipulating fewer control points.



For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/cageedit.htm#Cage).
