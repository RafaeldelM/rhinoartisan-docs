# Scale By Dimensions

## ​<img src="../../../.gitbook/assets/G4_02_TRANSFORMATION_SCALE_BY_DIMENSIONS.png" alt="" data-size="line"> Scale by Dimensions <a href="#scale-by-dimensions" id="scale-by-dimensions"></a>

This command allows us to scale any design using specific measurements rather than factors, as in other commands. It will enable us to scale independently on the X, Y, and Z axes or maintain proportions.

![](/img/v60/Scale by Dimension.jpg>)

We will select the objects to scale, and it will show us a real-time preview of how the model will look. Any changes we make will be visible! It's excellent for dynamically adjusting parts to fit others.
