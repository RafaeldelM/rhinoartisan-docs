# Align Gems

## <img src="../../.gitbook/assets/G7_02_TRANSFORM_ALIGN_GEMS.png" alt="" data-size="line"> Align Gems <a href="#profiles" id="profiles"></a>

The **Align Gems** command allows users to quickly align gems in the viewport to a selected surface, providing flexibility in positioning and orientation.

<figure><img src="../../.gitbook/assets/image (676).png" alt=""><figcaption></figcaption></figure>

**Key features:**

1. **Surface Alignment:** Select a surface to which the gems will be aligned.
2. **Flip Option:** Toggle the orientation of the gems for optimal placement.
3. **Adapt or Keep Orientation:**
   * _Adapt to Object_: The gems will adjust their orientation to match the surface.
   * _Keep Orientation_: The gems will maintain their current orientation while aligning to the surface.
4. **Alignment Modes:**
   * _Align from the Table_: Aligns the gems with the table (the top, flat facet).
   * _Align from the Girdle_: Aligns the gems with the girdle (the widest part of the gem).

This command simplifies gem alignment, ensuring precision while offering customizable orientation options.

<figure><img src="../../.gitbook/assets/Anillo pave irregular.jpg" alt=""><figcaption></figcaption></figure>

:::info
Goldsmith tip : This command is particularly useful when arranging a pavé on a domed or curved surface. You can first distribute circles in the CPlane to perfect the arrangement, and once you're satisfied with the layout, you can convert the circles into gems with the command Gems from Circles. Then, use the **Align Gems** command to snap the gems to the surface of the object you're designing. This ensures a smooth transition from a flat layout to a perfectly aligned design on a complex surface.
:::
