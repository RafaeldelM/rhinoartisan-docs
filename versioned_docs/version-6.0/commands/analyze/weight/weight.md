# Weight

## <img src="../../../.gitbook/assets/OUT_WEIGHT_BLACK (1).png" alt="" data-size="line"> Weight

This command will calculate the weight of our design, considering the weight of the metals and gems. In this case, we only have one type of metal and diamonds, but it will show the complete list in cases where we have several.

<figure><img src="../../../.gitbook/assets/Weight (1).jpg" alt=""><figcaption><p>Document Weight Example</p></figcaption></figure>

:::info
This command analyzes the entire document. To get information about the weight of a specific object or objects, you can use the "[Weight by Selection](weight-by-selection.md)" command.
:::

The default metal value is shown in the [**Outliner**](../../../user-interface/panels/outliner/). You can change it, and it will affect the weight, rendering, etc.
