# Length

## <img src="../../../.gitbook/assets/ANALYZE_MEASURE_LENGHT.png" alt="" data-size="line"> Length

The Length command reports the length of curves or edges.

### **Supported input:**&#x20;

* Curves
* Mesh/SubD edges

When multiple objects are selected, the accumulated length is displayed in the command history.

Cumulative length is calculated from all curves in a group unless using Ctrl+Shift+click to select group members separately.

Group members that are hidden or on hidden layers will not be calculated.

### Command-line options

**Units:** Set the units for the length display.

**SubCrv:** Type subcrv to select part of a curve as input.

For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/length.htm).
