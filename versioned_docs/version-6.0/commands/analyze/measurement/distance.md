# Distance

## <img src="../../../.gitbook/assets/ANALYZE_MEASURE_DISTANCE.png" alt="" data-size="line"> Distance

The Distance command reports the distance between two points.

### **Steps**

1. Pick the first point.
2. Pick the second point.\
   The distance between the points is displayed in the command history window, with angles and distances in the axis directions in world and construction plane coordinates.

### Command-line options

**Units:** Set the units for the distance display.

For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/distance.htm).
