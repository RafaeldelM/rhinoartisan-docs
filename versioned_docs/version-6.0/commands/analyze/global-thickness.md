# Global Thickness

### <img src="../../.gitbook/assets/ANALYZE_ANALYZE_GLOBAL_THICKNESS (3).png" alt="" data-size="line"> Global Thickness

This command allows us to visually and globally analyze our jewellery, setting a minimum measurement. By default, the command uses 0.6 mm as a reference for resin printing and metal casting.
