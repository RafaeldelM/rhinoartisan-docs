# Balancer Checker

## <img src="../../.gitbook/assets/ANANYZE_BALANCE_CHECKER.png" alt="" data-size="line"> Balancer Checker

This command allows us to calculate the position of objects based on gravity, making it ideal for determining how a pendant will naturally fall. We will select two groups of objects: the base object (which will remain fixed and serve as a reference) and the objects to be oriented.
