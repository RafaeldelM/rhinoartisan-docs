# Curve from Gems

## ​<img src="../../../.gitbook/assets/G6_10_DIAMOND_CURVE_FROM_GEMS.png" alt="" data-size="line"> Curve from Gems <a href="#auto-join-1" id="auto-join-1"></a>

With this command, you can create a curve following the center of multiple stones. It's especially useful to generate custom geometry for your designs around its gems.

<figure><img src="../../../.gitbook/assets/Curve from Gems.png" alt=""><figcaption><p>Curve from Gems  Selecting Gems</p></figcaption></figure>

It is effortless: select two or more gems, and a curve will be created automatically.
