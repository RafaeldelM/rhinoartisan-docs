# Recover

## ​<img src="../../../.gitbook/assets/G6_03_DIAMOND_GEM_RECOVER.png" alt="" data-size="line"> Recover <a href="#recover" id="recover"></a>

This command allows us to convert any gem created in other plugins, such as RhinoGold, Matrix, or MatrixGold, into RhinoArtisan gems, and work with them as if they were made in RhinoArtisan.

<figure><img src="../../../.gitbook/assets/Recovery 1 (1).jpg" alt=""><figcaption><p>Modelado con MatrixGold</p></figcaption></figure>

Select the gems to convert them, and that's it!

<figure><img src="../../../.gitbook/assets/Recovery 2.jpg" alt=""><figcaption><p>Result after converts to RhinoArtisan</p></figcaption></figure>

Sometimes the recovered stones may appear flipped. To correct their orientation, use our [Turn Upside Down](turn-upside-down.md) command to reverse their position..

:::warning
We should note that MatrixGold creates blocks for each gem. Therefore, we recommend selecting the gems and using the **ExplodeBlock** command to break down the blocks and obtain a convertible mesh.
:::
