# Color by Size

## <img src="../../../.gitbook/assets/G6_02_DIAMOND_COLOR_BY_SIZE.png" alt="" data-size="line"> Color by Size

This command allows us to change the color of the gems based on their size. It's excellent for analyzing or selecting gems by their dimensions.

Counting or locating specific gem sizes within a pavé can be a time-consuming task.

<figure><img src="../../../.gitbook/assets/image (679).png" alt=""><figcaption></figcaption></figure>

&#x20;The 'Color by Size' command simplifies this process by visually distinguishing groups of gems of the same size with different colors. This makes it quick and easy to identify and differentiate gem sizes, ensuring a clear and accurate visualization :

<figure><img src="../../../.gitbook/assets/image (683).png" alt=""><figcaption></figcaption></figure>

:::info
**Goldsmith Tip:** "Using this tool together with the gem selection feature in the Outliner allows you to quickly count, locate, and visualize all the different gem sizes at a glance.
:::
