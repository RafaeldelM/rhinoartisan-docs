# Gems Move

## <img src="../../../.gitbook/assets/G6_05_DIAMOND_GEM_MOVE.png" alt="" data-size="line"> Gems Move

This command allows us to move gems globally while each one follows its direction. This tool is crucial for adjusting pavés or complex gem structures.

<figure><img src="../../../.gitbook/assets/Move Gems.jpg" alt=""><figcaption></figcaption></figure>

1. Select gems to move
2. Set the distance. This parameter can be negative.
