# Micro Setting

### ​<img src="../../../.gitbook/assets/G5_02_DIAMOND_MICRO_SETTINGS.png" alt="" data-size="line"> Micro Setting <a href="#micro-setting" id="micro-setting"></a>

The **Microsetting** command is designed to create all the necessary cutters required for a microsetting, specifically for use in a subsequent **Boolean Difference** operation. This command helps you prepare precise gaps in the base object where gemstones will later be set.

<figure><img src="../../../.gitbook/assets/image (612).png" alt=""><figcaption></figcaption></figure>

This tool is ideal for crafting traditional micro settings and working with complex designs. It allows for the creation of cutters that match the shape and placement of the gems you plan to use, ensuring accuracy and efficiency during the setting process.

### **Cutters**&#x20;

The main cutter for the gemstones is controlled in this panel. You can choose between different cutter shapes and adjust parameters like height and width. The width can be tapered independently for each side, making it easier to account for curved surfaces where one side needs to be thicker than the other.

<div align="left"><figure><img src="../../../.gitbook/assets/image 238.png" alt="" width="254"><figcaption></figcaption></figure></div>

Height: Adjusts the height of the cutter.

Widht: Adjusts the width of the cutter

Lenght: Adjusts the lenght of the cutter

Move in Z: Allows you to adjust the height of the cutter along the Z-axis.

Move Middle in Z: Allows you to adjust the height of the cutter along the Z-axis, of the middle part.

Shape: You can customize the shape of the cutter.

* U Shape
* V Shape
* Square Shape
* Trapezoidal Shape
* French

Mode: Allows you to modify both sides at the same time or to modify each side independently.

Shape Scale: Allows to set the proportion of the shape in proportion to the total cutter.

### **V Prongs**

This panel allows you to create V-shaped cutters between stones. While some setters prefer to add these cuts manually, this feature automates the process, giving you full customization of the V-prong cuts to match the design.

<div align="left"><figure><img src="../../../.gitbook/assets/image 240.png" alt="" width="254"><figcaption></figcaption></figure></div>

Height: Adjusts the height of the V prong.

Widht: Adjusts the width of the V prong

Lenght: Adjusts the lenght of the V prong

Move in Z: Allows you to adjust the height of the V prong along the Z-axis.

Mode: Allows you to modify both sides at the same time or to modify each side independently.

### **V Channel**

Similar to the Cutters panel, this section allows you to shape the V-channel between the stones. You can choose between flat or round ends, and even extend the ends if required.

<div align="left"><figure><img src="../../../.gitbook/assets/image (160).png" alt=""><figcaption></figcaption></figure></div>



Height: Adjusts the height of the cutter.

Widht: Adjusts the width of the cutter

Move in Z: Allows you to adjust the height of the V prong along the Z-axis.

Extension : Extends the end of the channel&#x20;

Bend : Bends the end of the channel to its side ( negative amount would bend it to the opposite side if needed )

Shape U : We can select the shape of the channel cutter between U, V,  Square or Trapezoidal shape. With the slider that is below this parameter we can change the tangency of the U and V shape or move in Z when the Square or the trapezoidal shapes are selected.

Profile: We can here flip the profile and the ends to adjust the direction on which the channel is constructed.

Precise : This feature allows for a more precise channel, especially in cases where the shape of the object being used to construct the channel is highly curved or has double curvature.

### **Prongs In A Row**

This optional panel lets you reinforce the space between the stones with prong-shaped cutters. Activating this panel displays an orange sphere, which you can drag to position the prong cutters precisely, ensuring they are well-aligned with your design.

<figure><img src="../../../.gitbook/assets/image (613).png" alt=""><figcaption></figcaption></figure>



Once the cutters are generated, they can be used in a **Boolean Difference** operation to carve out the appropriate spaces in the object where the gemstones will be set.
