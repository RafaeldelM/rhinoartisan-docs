# Middle Button

By pressing the wheel on your mouse, this window will be displayed. You will find convenient shortcuts to commonly used commands and features.

<figure><img src="../.gitbook/assets/image 69 (1).png" alt=""><figcaption></figcaption></figure>

Clicking icons will execute the corresponding command or open related command groups.

**Visibility and Locking Tools**

<div align="left"><figure><img src="../.gitbook/assets/Frame 20.png" alt="" width="270"><figcaption></figcaption></figure></div>

* **Hide**: Hides selected objects. [More info](https://docs.mcneel.com/rhino/8/help/en-us/commands/hide.htm?Highlight=hide)
* **Show**: Shows all hidden objects. [More info](https://docs.mcneel.com/rhino/8/help/en-us/commands/hide.htm#Show)
* **ShowSelected**: Shows only selected hidden objects. [More info](https://docs.mcneel.com/rhino/8/help/en-us/commands/hide.htm#ShowSelected)
* **Select objects to hide**: Choose objects to hide.
* **Invert Hide**: Inverts the visibility of hidden and shown objects.

**Locking Tools**

<div align="left"><figure><img src="../.gitbook/assets/Frame 21.png" alt="" width="270"><figcaption></figcaption></figure></div>

* **Lock objects**: Locks selected objects. [More info](https://docs.mcneel.com/rhino/8/help/en-us/commands/lock.htm?Highlight=lock)
* **Unlock Objects**: Unlocks all locked objects. [More info](https://docs.mcneel.com/rhino/8/help/en-us/commands/lock.htm?Highlight=lock)
* **Unlock selected**: Unlocks only selected objects.
* **Isolate/Unisolate objects**: Isolates the selected objects or returns them to the prior state.[ More info](https://docs.mcneel.com/rhino/8/help/en-us/commands/lock.htm#IsolateLock)
* **Swap locked and unlocked objects**: Switches the lock state between locked and unlocked objects. [More info](https://docs.mcneel.com/rhino/8/help/en-us/commands/lock.htm#LockSwap)

**Grouping Tools**

<div align="left"><figure><img src="../.gitbook/assets/Frame 22 (1).png" alt="" width="270"><figcaption></figcaption></figure></div>

* **Group objects**: Groups selected objects. [More info](https://docs.mcneel.com/rhino/8/help/en-us/commands/group.htm?Highlight=group%20objects)
* **Ungroup objects**: Ungroups selected objects. [More info](https://docs.mcneel.com/rhino/8/help/en-us/commands/group.htm#Ungroup)
* **Add to group**: Adds objects to an existing group. [More info](https://docs.mcneel.com/rhino/8/help/en-us/commands/group.htm#AddToGroup)
* **Remove from group**: Removes objects from an existing group. [More info](https://docs.mcneel.com/rhino/8/help/en-us/commands/group.htm#RemoveFromGroup)
* **Set group name**: Assigns a name to a selected group. [More info](https://docs.mcneel.com/rhino/8/help/en-us/commands/group.htm#SetGroupName)

**View Control**

<div align="left"><figure><img src="../.gitbook/assets/Frame 23.png" alt="" width="270"><figcaption></figcaption></figure></div>

* **Set top view**: Switches to top view. [More info](https://docs.mcneel.com/rhino/8/help/en-us/commands/setview.htm?Highlight=top%20view)
* **Set bottom view**: Switches to bottom view. [More info](https://docs.mcneel.com/rhino/8/help/en-us/commands/setview.htm?Highlight=top%20view)
* **Set front view**: Switches to front view. [More info](https://docs.mcneel.com/rhino/8/help/en-us/commands/setview.htm?Highlight=top%20view)
* **Set left/right view**: Switches to left or right view. [More info](https://docs.mcneel.com/rhino/8/help/en-us/commands/setview.htm?Highlight=top%20view)
* **Set perspective view**: Switches to perspective view. [More info](https://docs.mcneel.com/rhino/8/help/en-us/commands/setview.htm?Highlight=top%20view)

**Surface Editing**

<div align="left"><figure><img src="../.gitbook/assets/Frame 24.png" alt="" width="270"><figcaption></figcaption></figure></div>

* **Trim/Untrim**: Trims or restores edges on surfaces. [More info](https://docs.mcneel.com/rhino/8/help/en-us/commands/trim.htm?Highlight=trim)
* **Split/Split surface by isocurve**: Splits surfaces by isocurve. [More info](https://docs.mcneel.com/rhino/8/help/en-us/commands/split.htm?Highlight=split)
* **Join/Join surfaces**: Joins surfaces. [More info](https://docs.mcneel.com/rhino/8/help/en-us/commands/join.htm?Highlight=join)
* **Explode/Extract surface**: Explodes or extracts surfaces. [More info](https://docs.mcneel.com/rhino/8/help/en-us/commands/explode.htm?Highlight=explode)

**Selection Tools**

<div align="left"><figure><img src="../.gitbook/assets/Frame 25.png" alt="" width="375"><figcaption></figcaption></figure></div>

* **Select all**: Selects all objects. [More info](https://docs.mcneel.com/rhino/8/help/en-us/commands/selection_commands.htm?Highlight=select%20all#AllObjects)
* **Select none**: Deselects all objects. [More info](https://docs.mcneel.com/rhino/8/help/en-us/commands/selection_commands.htm#SelNone)
* **Invert selection**: Inverts the current selection. [More info](https://docs.mcneel.com/rhino/8/help/en-us/commands/selection_commands.htm?Highlight=invert%20selection#Invert)
* **Show last object**: Displays the last hidden object.
* **Select previous selection**: Recalls the last selection.
* **Select exact duplicate objects**: Selects objects that are exact duplicates.
* **Select rectangle region**: Selects objects within a rectangular region.

**Advanced Selection**

<div align="left"><figure><img src="../.gitbook/assets/Frame 26.png" alt="" width="375"><figcaption></figcaption></figure></div>

* **Select by color**: Selects objects by color.
* **Select by layer**: Selects objects by their layer. More info
* **Select dots**: Selects dot annotations.
* **Select dimensions/select text blocks**: Selects dimensions or text blocks. More info
* **Select by lasso**: Selects objects using a free-form lasso.
* **Select group**: Selects grouped objects.
* **Select clipping plane in viewport**: Selects the clipping plane in the viewport.

**Solid and Mesh Selection**

<div align="left"><figure><img src="../.gitbook/assets/Frame 27.png" alt="" width="375"><figcaption></figcaption></figure></div>

* **Select solids**: Selects solid objects.
* **Select closed solids**: Selects closed solids. More info
* **Select open solids**: Selects open solids.
* **Select meshes**: Selects mesh objects.
* **Select closed meshes**: Selects closed meshes.
* **Select open meshes**: Selects open meshes.
* **Select mirrored blocks**: Selects mirrored block instances.

**Curve and Surface Selection**

<div align="left"><figure><img src="../.gitbook/assets/Frame 28.png" alt="" width="327"><figcaption></figcaption></figure></div>

* **Select points**: Selects point objects.
* **Select curves**: Selects curve objects.
* **Select short curves**: Selects short curves.
* **Select surfaces**: Selects surface objects.
* **Select SubD**: Selects SubD geometry.
* **Select faces to boundary**: Selects faces within boundaries.
* **Select bad objects**: Selects any invalid or problematic objects. More  info

**Document and Edit Tools**

<div align="left"><figure><img src="../.gitbook/assets/Frame 29.png" alt="" width="327"><figcaption></figcaption></figure></div>

* **Edit**: Opens edit commands.
* **Undo**: Reverses the last action.
* **Redo**: Re-applies the last undone action.
* **New document**: Creates a new document.&#x20;
