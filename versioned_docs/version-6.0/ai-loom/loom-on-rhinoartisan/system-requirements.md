# System Requirements

## System Requirements

Loom is part of RhinoArtisan and follows the same technical requirements as the main application, with a few additional considerations to ensure a smooth, real-time experience.

**Minimum Requirements**

Your system must meet at least:

* **Operating System:** Windows 10 / Windows 11 (64-bit)
* **Rhino Version:** Rhino 7 or Rhino 8 installed
* **RhinoArtisan Version:** RhinoArtisan 6.3 or later
* **Processor:** Intel i5 / AMD Ryzen 5 or equivalent
* **Memory (RAM):** 8 GB
* **Graphics:** GPU compatible with OpenGL 4.1
* **Internet Connection:** Required (Co-designer uses cloud computation)

**Recommended Requirements**

For the best performance:

* **Processor:** Intel i7 / AMD Ryzen 7 or better
* **Memory (RAM):** 16 GB or more
* **Graphics:** NVIDIA RTX-series or equivalent modern GPU
* **Storage:** SSD (Solid State Drive)

**Internet Connectivity**

Loom relies on online computation for AI-powered features and real-time processing. This means:

* The system **does not run the AI locally**
* A **stable internet connection** is required at all times
* Some operations may take longer on slow or unstable networks
* In-store Wi-Fi should be reliable to ensure a smooth customer experience

**Additional Notes**

* Loom is available for all RhinoArtisan and RhinoArtisan Connect users, with no limitations.
* To use Loom, you only need a **RhinoArtisan Connect account** — any plan works, including the **free** one.
* Performance may vary depending on model complexity and network conditions.
* System requirements may evolve over time as Loom grows and new features are added.
