# SubD Dragon Modeling

In this video, we guide you through modeling a **dragon** using powerful SubD tools inside RhinoArtisan. You'll learn how to create complex organic shapes, apply textures, set up cutters, and render your final design with professional lighting and materials.

<figure><img src="../../../.gitbook/assets/Dragon 4k.jpg" alt=""><figcaption></figcaption></figure>

Whether you're a jeweler, CAD designer, or 3D modeling enthusiast, this tutorial will level up your skills in organic sculpting and jewelry design.

📌 **What You’ll Learn:**\
✔ How to use SubD symmetry and soft transforms for organic modeling\
✔ How to texture models using custom 3D textures\
✔ How to use cutters and boolean tools for gemstone settings\
✔ How to set up materials, lighting, and rendering using RhinoArtisan
