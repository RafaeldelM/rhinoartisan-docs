# Moebius Diamond Pendant

In this video, we take you step by step through modeling an elegant Moebius pendant using RhinoArtisan. You’ll learn how to construct flowing curves with mathematical precision, generate a solid using rail sweeps, and integrate gemstones with prongs and cutters for a polished, professional result.\
Perfect for jewelry designers and CAD modelers aiming to explore dynamic geometry with clean execution.

📌 What You’ll Learn:\
✔ How to model and refine Moebius-inspired curves\
✔ How to create solids using rails and profiles\
✔ How to set diamonds precisely with prongs and cutters
