# Diamond Infinity Pendant

In this video, we guide you through modeling an elegant Infinity Pendant using RhinoArtisan’s precise and intuitive tools. You’ll learn how to design fluid curves, create profiles and apply diamond settings.

Whether you're a jeweler, CAD designer, or 3D artist, this tutorial will sharpen your skills in clean geometric modeling and fine jewelry detailing.

📌 What You’ll Learn:\
✔ How to create smooth, continuous curves for symbolic designs\
✔ How to set diamonds with precision and control\
✔ How to manage symmetry and create profiles using RhinoArtisan tools
