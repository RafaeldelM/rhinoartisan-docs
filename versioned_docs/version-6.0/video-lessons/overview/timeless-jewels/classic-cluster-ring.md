# Classic Cluster Ring

This tutorial teaches you how to design a Classic Cluster Ring. You'll start by creating a 1-carat diamond centerpiece and adjust its position for a balanced look. Then, you'll configure the double-layered gem rail and prongs to securely hold the gemstones. The Cathedral Shank style will be used for the band, and you'll add a bridge for stability. Finally, you'll review and render the design to ensure everything fits perfectly.
