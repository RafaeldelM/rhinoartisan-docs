# Domed Pavé Signet Ring

**Welcome to RhinoArtisan!**

In this tutorial, we’ll walk you through the complete process of modeling a **Domed Pavé Signet Ring**. Starting with a custom signet shank, we’ll design a smooth base, build reference curves, and generate a domed surface ready for pavé setting. You’ll learn how to hollow the ring for optimized weight, create precise surfaces, and prepare a structure that balances strength and elegance.

Next, we’ll move on to gem setting — using Pavé Along Surface and Automatic Pavé to fill the dome with diamonds. Step by step, we’ll customize gem sizes, refine spacing, and generate prongs and cutters for a professional, production-ready pavé arrangement. Finally, we’ll apply finishing touches and prepare the model for rendering or manufacturing.
