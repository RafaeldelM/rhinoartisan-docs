# Elegant Pear Drop Pendant

Welcome to RhinoArtisan!
\
In this tutorial, we’ll guide you step by step through the complete process of creating a heart-shaped pavé pendant with a pear gemstone centerpiece using RhinoArtisan’s advanced jewelry CAD tools.
\
Starting from an asset curve, we’ll build the base shape using ellipses and sweep surfaces, refine the geometry, and create a recessed area prepared for pavé gemstone placement. You’ll learn how to control surfaces with isocurves, generate gemstone areas using Push & Pull, and create an elegant pavé layout using RhinoArtisan’s automatic pavé tools.
\
We’ll then add prongs, apply cutters to prepare the model for manufacturing, and finish the pendant by creating the central gemstone basket, support structure, and bail. The final result is a clean, production-ready jewelry model ready for rendering or manufacturing.

📌 What You’ll Learn:
\
✔ Creating the base shape using curve assets and scaling tools
\
✔ Building a pendant structure using ellipses and Sweep Two Rails
\
✔ Using isocurves and blends to define pavé gemstone areas
\
✔ Creating recessed gemstone zones with Push & Pull
\
✔ Generating pavé layouts with Automatic Pavé tools
\
✔ Adding and refining prongs for gemstone settings
\
✔ Preparing the model for production using cutters and Boolean operations
\
✔ Creating a pear-shaped gemstone basket and support structure
\
✔ Designing and customizing a pendant bail and loop
