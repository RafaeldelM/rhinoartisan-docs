# Three-stone Princess Ring

Welcome to RhinoArtisan!
\
In this tutorial, we’ll guide you step-by-step through the complete process of modeling a Three-Stone Engagement Ring. Starting with a custom shank design, we’ll create a smooth and elegant band, add accurate settings, and position a princess-cut center stone with trillion-cut side stones. You’ll learn how to build precise prongs, prepare clean geometry, and achieve a refined, production-ready model.

📌 What You’ll Learn:
\
✔ Designing a three-stone engagement ring from scratch
\
✔ Building a smooth shank
\
✔ Creating accurate seats for princess and trillion-cut stones
\
✔ Customizing prongs and supports for secure stone setting
\
✔ Applying Boolean operations for clean manufacturing geometry
\
✔ Optimizing the structure for strength and ergonomic comfort
\
✔ Preparing a full jewelry CAD for rendering or production
