# How to Resize Rings Precisely

Welcome to RhinoArtisan!\
In this tutorial, you’ll learn how to use the powerful **Ring Resizer** tool to adjust your ring designs to multiple sizes while maintaining the original proportions and intricate details—perfect for production or presentation.

📌 What You’ll Learn:\
✔ Accessing and using the Ring Resizer command in the Manufacturing tab\
✔ Selecting the shank and protecting key design areas by using the Variable mode\
✔ Setting the resizing angle to preserve the gem setting and other features\
✔ Defining multiple target ring sizes for automatic scaling\
✔ Using the Identifier tab to label each resized ring clearly\
✔ Adjusting sprue parameters for each size and activating them\
✔ Verifying the resized rings with correctly aligned settings and gemstones\
✔ Finalizing the scaled models ready for production or presentation

📌 Tools Used: RhinoArtisan — Manufacturing tab, Ring Resizer command, Gumballs, Identifier, Sprue settings
