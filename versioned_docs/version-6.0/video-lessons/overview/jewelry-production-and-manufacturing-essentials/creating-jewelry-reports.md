# Creating Jewelry Reports

**Welcome to RhinoArtisan!**\
In this tutorial, you’ll learn how to generate a professional report ready for printing directly from RhinoArtisan. This process covers setting up your breakdown details, customizing report data, adding dimensions, and updating materials—all to produce a comprehensive document showcasing your model’s specifications.

📌 **What You’ll Learn:**\
✔ Verifying and completing breakdown settings in the Manufacturing tab\
✔ Automatically generating model details and breakdown information\
✔ Filling in custom report fields such as Client ID, Product Order, Style, and Designer\
✔ Selecting and applying report templates\
✔ Editing model views and display modes within the report\
✔ Adding dimension annotations for precise measurements\
✔ Managing materials (e.g., White Gold, Rose Gold) and reflecting changes dynamically\
✔ Finalizing the report and preparing it for 3D printing or PDF export

📌 **Tools Used:** RhinoArtisan — Manufacturing, Files, Drafting tabs, Breakdown Settings, Report Generator
