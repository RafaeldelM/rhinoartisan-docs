# Eternal Weave Ring

**Welcome to RhinoArtisan!** In this in-depth tutorial, we’ll guide you through modeling an elegant gemstone ring using RhinoArtisan’s powerful tools. Designed for both jewelers and 3D designers, this step-by-step video covers every stage — from sketching curves to applying Smart Flow, placing stones, and refining intricate details for production and rendering.

📌 **What You’ll Learn**:\
✔ Use ring size presets and Smart Flow for perfect shaping\
✔ Add gems and adjust spacing automatically\
✔ Generate prongs and channels using MicroSettings\
✔ Create and trim custom profiles with precision\
✔ Prepare your ring for rendering or 3D printing
