# Reference Curve and Gem

### **Step 1:  Curve Command**

**I**n the **Shanks** tab, use the **Curve** command.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-2-300x111.png)

### **Step 2: Finger Size**

This time, select the **USA size 6 ½**  for the reference curve.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/ReferenceCurveSize.png)

### **Steps 3: Gem Studio**

Go to the **Diamonds** tab and use the **Gem Studio** command.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Gem-Studio-TOOLBAR.png)

Create a **1-carat gem** (1). Change the alignment to **Culet** (2).

Use the '**Add Gem on a Point**' (3) option, then click on the upper point of the reference curve (4).

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Place-Gems.png)

&#x20;

### **Steps 4:  Pose**

Using the gumball, move the gem 2.30 **millimeters upward** from the culet.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/2.3.png)
