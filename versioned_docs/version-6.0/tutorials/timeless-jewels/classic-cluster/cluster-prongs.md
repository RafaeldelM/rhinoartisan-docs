# Cluster Prongs

This lesson will focus on the **Prongs Tab.**

### Starting with the **Prongs Tab**:

* **Mode**: 3º

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Screenshot-2024-11-12-172817.png)

### Now, for the **Internal Prongs**:

* **Diameter**: 1.3 mm
* **Distance**: 0.9 mm
* **Height Over Girdle**: 1 mm
* **Height Under Girdle**: 3.6 mm
* **Move in Z**: 0
* **Gems Extension for Manufacturing**: 0.5 mm

These internal prongs will securely hold the gemstones in place while keeping them aligned.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/PARAMETERS-cluster-prongs.png)

### The **External Prongs**:

* **Diameter**: 1.4 mm
* **Distance**: 1.2 mm
* **Height Over Girdle**: 1.1 mm
* **Gems Extension for Manufacturing**: 0.5 mm
* **Move in Z**: 0

### **Central External Prong**

Now, let’s set up the **Central External Prong**:

* **Diameter**: 1.1 mm
* **Gem Inside**: 0.1 mm
* **Height Over Girdle**: 0.7 mm
* **Gems Extension for Manufacturing**: 0.5 mm
* **Move in Z**: 0

These external prongs secure the cluster and give a refined, stable look to our design.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/PARAMETERS-cluster-prongs2.png)
