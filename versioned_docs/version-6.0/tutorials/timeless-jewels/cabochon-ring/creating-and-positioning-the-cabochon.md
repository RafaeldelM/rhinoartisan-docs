# Creating and Positioning the Cabochon

### **Line Command**

Go to the **Curve** tab (1) and create a **line** (2) that runs across the top of the ring. This will help with positioning.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/LineCommand.png)

### Osnap

Activate **Osnap** and select options to align it accurately.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/OSnap.png)

### Create the line.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Line.png)

### **Create the Cabochon**

Go to the **Diamonds** tab (1) and select **Cabochon** (2).

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/CabochonCommand.png)

* Set the **Mode** to **Oval**.
* Set **X** to 8 mm, **Y** to 10 mm, **Z** to 3 mm.
* Set the **Girdle Angle** to **0**.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Cabochon-Parameters.png)

### **Position the Cabochon**

* Use the line created earlier to find the **midpoint** and place the cabochon in the center of the shank.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Place-Mid.png)
