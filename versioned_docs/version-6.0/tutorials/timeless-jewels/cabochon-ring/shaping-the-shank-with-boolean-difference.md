# Shaping the Shank with Boolean Difference

### **Boolean Difference**

In the **Solid** tab, select **Boolean Difference**.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Boolean.png)

* Select the **shank**, press **Enter**, then select the offset solid, and press **Enter** again.

### **Check Shank Fit**

* Use **Hide** to conceal the gem and examine the seat created in the shank.
* Use **Show** to bring the cabochon back.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Boolean.png)
