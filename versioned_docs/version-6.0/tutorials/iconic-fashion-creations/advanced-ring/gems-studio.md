# Gems Studio

### **Step 1: Gem Studio**

Run the "Gem Studio" command.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Gem-Studio-TOOLBAR-1024x141.png)

### **Step 2: Gem Parameters**

Create a half-carat, round stone. Click “Add.”

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-5-499x1024.png)

### **Step 3: Move Command**

In the "Transform" tab, use the "Move" command to position the gem.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-6.png)

### **Step 4: Osnap**

Ensure "Vertex" and "Mid" options are enabled in the Osnap panel.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-7-2-1024x355.png)

### **Step 5: Place Gem**

Click the bottom of the gem and Place the gem on the top point of the curve.

![](/img/v60/Position.png)

### **Step 6: Gumball**

Use the Gumball tool to move the gem 1 millimeter upwards.

![](/img/v60/1.00.png)
