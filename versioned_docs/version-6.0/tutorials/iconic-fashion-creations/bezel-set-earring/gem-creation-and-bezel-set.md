# Gem Creation and Bezel Set

### **Step 1**: **Gems from Circle**

Use the **Gems from Circles** command from the **Diamonds** tab to generate gems from the **inner curves**.

![](/img/v60/GemsByCircles.png)

### **Step 2**: Curator

Retrieve the bezel from the **Curator** panel. Select the **bezel**, add it to the workspace, and apply the saved bezel style to the gems.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/ApplyStyle-1024x335.png)
