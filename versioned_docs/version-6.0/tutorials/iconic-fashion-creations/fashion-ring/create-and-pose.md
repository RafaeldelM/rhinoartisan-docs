# Create and pose

### **Steps 1: Gems Studio**

In the "Diamonds" tab, use the "Gem Studio" command.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-70-1024x155.jpg)

### **Steps 2:  Create the Gem**

Create a 1.50-carat **(1)** oval stone. For vertical alignment, set the option to "Culet" **(2)** and click "Add."

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-71.jpg)

### **Steps 4: Visualization**

Switch to the perspective view by double-clicking on "Perspective." Use "Pan, Zoom, and Rotate" followed by "Zoom Extents All" for better visualization.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/image-1259-1024x575.jpg)

### **Steps 6: Pose the gem**

In the "Transform" tab, use the "Move" command to position the gem. Move it to the top of the curve created earlier.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-71-2-1024x99.jpg)

> Activate Osnap and select Point, Vertex, Mid and Knot

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-72.jpg)

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/image-1263-1024x615.jpg)

Use the Gumball to move the gem 1.5 millimeters upward and rotate it 90 degrees.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/image-1264-1024x574.jpg)
