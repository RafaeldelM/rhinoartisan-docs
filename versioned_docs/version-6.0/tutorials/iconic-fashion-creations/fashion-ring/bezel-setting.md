# Bezel Setting

### **Step 1:  Bezel Command**

In the "Diamonds" tab, select the Gem and then the "Bezel" command.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-73-1-1024x146.jpg)

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/image-1266-1024x573.jpg)

### **Step 3: Bezel Library**

Choose the BE034 model and click "Edit."

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-74-1024x414.jpg)

### **Step 4: Parameters**

Change the height of the bezel to 6.1 millimeters.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-74-1.jpg)
