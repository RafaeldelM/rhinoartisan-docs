# Edit Profiles

### **Step 1: Lower Profiles**

Take note of the lower profiles numbers and edit them.&#x20;

<figure><img src="../../../.gitbook/assets/LowerProfiles.png" alt=""><figcaption></figcaption></figure>

Change the profile curve to number 084, then adjust the width to 1.8 mm and the height to 1.7 mm.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/12/ParametrosProfileBot.png)

### **Step 2:** Parameters

Do the same for the other lower profile: change the profile to 084 and then adjust the width to 1.8 mm and the height to 1.7 mm.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/12/Finish.png)

### **Step 3: Bezel Cut**

Cut the bezel to match the height of the shank curve by selecting the "Cut" icon in the "Outliner."

* Select the bezel and then click on the "Cut" icon in the outliner.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Frame-5.jpg)

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Frame-6.jpg)
