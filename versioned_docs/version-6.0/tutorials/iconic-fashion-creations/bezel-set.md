# Bezel Set

In this tutorial, you’ll master the art of creating a stunning jewelry collection from start to finish.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Render-Final-1024x576.png)

### What You’ll Learn

Across four meticulously designed lessons, you’ll transform simple geometric shapes into a cohesive and luxurious set of jewelry pieces. Each step brings you closer to the final, polished result—complete with dazzling gemstones and elegant bezels. Here's what you'll discover:

### **Pendant Creation**

Start by crafting intricate reference curves and building a balanced design.![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/image-2024-10-18T134402.531-1024x900.png)

Through precise manipulation of patterns and gemstone settings, you’ll create a pendant that exudes elegance and sophistication.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Bail-1024x548.png)

### **Earrings Design**

Next, dive into designing matching earrings that follow the same aesthetic principles.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Pair_command_prompt-1024x319.png)

Learn how to create symmetrical patterns and seamlessly apply bezels, achieving a flawless pair of earrings.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Rotate_Orto-1024x319.png)

### **Ring Crafting**

The journey continues with a ring that complements the set perfectly.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/QuickFlow_panel-1024x291.png)

You’ll explore advanced techniques like curve adjustments and Quick Flow to ensure a harmonious and visually striking design.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/image-2024-10-18T134756.217-1024x639.png)

### **Full Collection Render**

In the final lesson, bring your collection to life. We’ll cover how to apply luxurious materials such as gold and gemstones, and render the entire set with breathtaking detail, making every curve and facet shine.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/08/Gems-1024x861.png)

By the end of this series, you'll not only have created a stunning jewelry collection but also mastered essential tools and techniques to elevate your 3D design skills. Prepare to create, refine, and shine!

### Who Should Take This Course?

This course is ideal for jewelry designers, CAD modelers, and creatives who want to bring precision, beauty, and innovation to their designs. Whether you’re new to 3D modeling or an experienced designer, this course provides essential techniques to create jewelry that stands out.

### What You’ll Need

You’ll only need RhinoArtisan installed. This course provides step-by-step guidance to build confidence, finesse, and a polished, professional piece.
