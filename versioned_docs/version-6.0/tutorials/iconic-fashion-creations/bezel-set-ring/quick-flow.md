# Quick Flow

### **Step 1: Ungroup**

To continue, we will ungroup all the curves. Select the curves and type **Ungroup** in the command bar.

### **Step 2: Quick Flow**

Now, go to the **Transform** tab and click on the **Quick Flow** command.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/QuickFlow-1024x113.png)

### **Step 3: Rigid Elements**

Select the inner curves of the pattern and click on **Rigid Elements** in the panel, as we don’t want the curves to deform.

<figure><img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/QuickFlow_panel-1024x291.png" alt=""><figcaption></figcaption></figure>

Next, choose the line as the base curve and the outer curve as the target curve. The curves are now properly positioned on the ring.
