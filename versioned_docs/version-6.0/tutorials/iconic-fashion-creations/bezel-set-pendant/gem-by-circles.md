# Gem by Circles

### **Step 1**: Hide

Hide the reference curves by selecting them and typing **Hide** in the command bar, then press **Enter**.

### **Step 2**: Use the Layer Panel

Right-click on the layer containing the inner curves to select them.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Pattern_sel.png)

### **Step 3**: Gems By Circles

In the **Diamonds** tab, use the **Gem by Circles** command to create your gemstones.

![](/img/v60/GemsByCircles.png)

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Gems_circles.png)
