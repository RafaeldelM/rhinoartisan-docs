# Bezel Setting

### **Step 1**: Copy the one Gem

Copy the top gemstone to create a bezel that will be used for the rest of the set.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Gems_circlesCOPY.png)

### **Step 2**: Bezel Command

Go to the **Diamonds Tab,** Select the gemstone and use the **Bezel** command.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-8-1-1024x144.png)

### **Step 3: Bezels Library**

Choose the **BE016** model and click **Edit**.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/BezelBE016-1-1024x273.png)

### **Step 4**: Reduce the Weight

Edit the profile curve to reduce the weight by adjusting **two points** as shown in the reference image.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Reff-Profile-1024x417.png)

### **Step 5**: Bezel Parameters

Adjust the height to **4.1 millimeters** and the **girdle width** to **0.6 millimeters**.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/BezelBE016_edit-1024x420.png)

**Step 7**: Save the bezel and gemstone by creating a new folder in the **Curator** panel.

* Click on **Add folder** ![](/img/v60/CURATOR_ADD_FOLDER_WHITE.png)
* **Name** the new folder
* Select the gem and basket
* Click on **Save on Curator** ![](/img/v60/OUT_HAND.png)
