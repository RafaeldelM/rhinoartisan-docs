# Quick Array Polar

### **Step 1:** Quick Array Polar

To finish this part, we will use the Quick Array Polar command. Select the model and press the command button in the transform tab.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/PolarArray-1024x175.png)

### **Step 2:** Quick Array Polar Panel

Click on the panel to add our element.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/image-18-1-300x118.png)

### **Step 3:** Parameters

Change the orientation to top and the number of copies to 4, then accept.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Screenshot-2024-07-18-at-12.32.12.png)
