# Stud Earrings

Stud earrings are small, often subtle, earrings that can feature a gemstone or be made entirely of metal. The most common example is a simple metal ball earring. Over time, it became fashionable to include diamonds in the design, usually set in a bezel or basket setting. Although these designs were originally intended for young girls, they quickly gained popularity among all age groups. Today, stud earrings are often characterized by a single diamond, which can be as large as 2 carats.
