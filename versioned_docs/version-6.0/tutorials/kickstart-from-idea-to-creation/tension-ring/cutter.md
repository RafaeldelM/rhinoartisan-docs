# Cutter

### **Step 1: Cutter Command**

Select the gem, then go to the "Diamonds" tab **(1)** and choose the "Cutter" command **(2)**.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Lesson-1-AddGems-3-1-1024x141.jpg)

### **Step 2: Parameters**

Adjust the cutter parameters:

* Set Girdle Height to 4%.
* Pavilion Height to 71%.
* Gem Inside to -0.01
* Activate the fourth cutter option to closely fit the cutter to the gem.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-44-1024x459.jpg)

### **Step 3: Boolean Difference**

In the "Solid" tab **(1)**, select the "Boolean Difference" command **(2)**.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Lesson-1-Boolean-1024x107.jpg)

First, select the shank and press "Enter". Then, select the cutter and press "Enter" again.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/image-1235-1024x568.jpg)

Use the "Hide" command to hide the gem and inspect the result.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-45-1024x568.jpg)

Then, use the "Show" command to make the gem visible again.
