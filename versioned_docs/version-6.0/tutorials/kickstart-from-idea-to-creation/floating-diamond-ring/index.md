# Floating Diamond Ring

In this immersive course, we’ll take you on a creative journey to design a stunning floating ring from start to finish. Whether you're a jewelry design enthusiast or a professional looking to refine your skills, this course breaks down each step with clear instructions and practical tips. By the end, you’ll have a finished design ready for rendering and display!

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/001-02-Floating-Ring-Render.png)

### What You’ll Learn

**Craft the Perfect Shank:** Begin with the fundamentals by crafting a sleek, classic shank using customizable tools to achieve the ideal shape and dimension.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Shank-1024x576.png)

**Modeling and Boolean Difference Mastery:** Turn curves into solids and refine each element using essential Boolean operations for professional-grade results.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Shank_hole-1024x367.png)

**Precision Gem Setting Techniques:** Dive into gemstone settings, create notches, and learn how to position stones perfectly using precise cutter commands for a flawless fit.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Shank_GEm-1024x367.png)

**Visualize with Stunning Render Techniques:** Transform your design with realistic renderings—select metals, diamonds, and finishes that bring your masterpiece to life.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-31-1024x685.png)

### Who Should Take This Course?

This course is ideal for jewelry designers, CAD modelers, and creatives who want to bring precision, beauty, and innovation to their designs. Whether you're new to 3D modeling or an experienced designer, this course provides essential techniques to create jewelry that stands out.

### What You’ll Need

This course provides step-by-step guidance to build confidence, finesse, and a polished, professional piece.
