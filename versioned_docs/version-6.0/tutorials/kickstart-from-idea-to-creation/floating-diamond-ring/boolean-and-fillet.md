# Boolean and Fillet

### **Step 1: Boolean Difference Command**

Go to the "Solid" tab **(1)** and select the "Boolean Difference" command **(2)**.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Lesson-1-Boolean-1024x107.jpg)

First, select the shank and press "Enter".

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-23-2-1024x626.jpg)

Then, select the solid and press "Enter" again.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-24-1024x580.jpg)

### **Step 2: Socket**&#x20;

Delete the curve, and the socket is now formed.

![](/img/v60/Socket.png)

Next, we will refine the edges of the socket.

### **Step 3: Fillet Edge Command**

In the "Solid" tab **(1)**, select the "Fillet Edge" command **(2)**.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Lesson-1-Fillet-1024x107.jpg)

### **Step 6: Fillet Parameters**

Set the fillet radius to `0.3 millimeters` in the command bar and press "Enter".

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/image-29-1-1-1024x117.png)

### **Step 7: FIllet Edges**

Select the edges of the socket by double-clicking on them. Press "Enter" **twice** to confirm.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-25-3-1024x552.jpg)

With the edges now smooth we are ready to add the gemstones.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/image-31-1024x553.jpg)
