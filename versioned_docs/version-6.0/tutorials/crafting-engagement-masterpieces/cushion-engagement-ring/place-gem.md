# Place Gem

### **Step 1: Osnap Options**

Ensure the Osnap options "Vertex" and "Mid" are enabled.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-7-2-1024x355.png)

### **Step 2: Move Command**

In the transform tab, selecct the Move command.&#x20;

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-6.png)

### **Step 3:  Pose**

Then select the bottom vertex of the gem and move it to the top of the reference curve.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/image-3-1-246x300.png)

### **Step 4: Using the gumball**

Using the gumball, move the gem 2.5 millimeters upwards for proper height.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/image-4-1.png)
