# Reference Curve and Gem Studio

### **Step 1:  Curve Command**

Go to the "Shanks" tab and select the "Curve" command.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-2-300x111.png)

### **Step 2:  Ring Size**

Set the region to "United States of America" and select size 7.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/image-1-2.png)

### **Step 3:**  Gems Studio

Switch to the "Diamonds" tab and use the "Gem Studio" command.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Gem-Studio-TOOLBAR-1024x141.png)

### **Step 4:  Add gem**

Select "Cushion" as the shape and set the size to 2 carats. Align the gem to the Culet, then press "Add."

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-1-1-155x300.png)
