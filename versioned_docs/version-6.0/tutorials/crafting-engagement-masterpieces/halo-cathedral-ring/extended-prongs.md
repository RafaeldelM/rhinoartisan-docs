# Extended Prongs

### **Step 1:  Edit Halo Prongs**

Select the halo setting and click "Edit." In the prongs section, activate the option extend to bridge, and change the Height to 3.60 millimeters.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-21-3-355x1024.png)

### **Step 2: Finalize the Ring**

Press "Accept" to finalize the ring design.
