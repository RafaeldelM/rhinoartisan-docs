# Cathedral: Gems

### **Step 1:  Gems Parameters**

Go to the "Gems" tab in the shank settings.

Adjust the following parameters:

* Gem size: 1.50 millimeters.
* Min distance between gems: 0.20 millimeters.
* Vertical position: -0.20 millimeters.
* Inner width: 0.55 millimeters.
* Inner height: 0.70 millimeters.
* Bring cut: 0.
* Margin: 0.70 millimeters.
