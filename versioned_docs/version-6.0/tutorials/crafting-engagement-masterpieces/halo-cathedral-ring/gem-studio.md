# Gem Studio

### **Step 1 :  Gems Studio**

Go to the "Diamonds" tab and select the "Gem Studio" command.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Gem-Studio-TOOLBAR-1024x141.png)

### **Step 2: Add gem**&#x20;

Select a 1-carat stone and change the vertical alignment to culet. Press "Add" and confirm the gem selection.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-1-496x1024.png)

&#x20;

### **Step 3: Pose**

Use the Gumball to move the gem 12.175 millimeters upwards.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Move-1-289x300.png)
