# Create Fittings for Casting

### **Step 1: Boolean Difference**

&#x20;In the **Solid** tab, select the **Boolean Difference** command.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Boolean.png)

1. Choose the **shank** and press enter.
2. In the command bar, set **DeleteCutters** to **No** to keep the basket for use as the cutter.
3. Select the **basket** and press enter.

### **Step 2:  Hide and Show**

Use the **Hide** command to hide the basket and gem. This will let you appreciate the result of the Boolean Difference.

You'll see that **4 perfect fittings** have been created using 4 of the 6 prongs.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Boolean-1.png)

Type **Show** in the command bar to display the elements again.
