# Basket Rails

### **Step 1: Upper Rail**

In the **Rail** options, adjust the parameters for the **Upper Rail**:

* Width: **1.5 millimeters**
* Height: **1.20 millimeters**
* Under Girdle: **1.15 millimeters**

### **Step 2: Lowe Rail**

For the **Lower Rail**, adjust:

* Width: **1.20 millimeters**
* Height: **1.5 millimeters**
