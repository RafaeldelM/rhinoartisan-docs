# Ground

To apply a material to the ground, we will go from the Render and Animation tab, a Grounds. To select a material, simply click on the reference image.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/08/Grounds-300x251.png)

Tip: When we select a material for the floor, it will be created at the height of the element that is closest to the surface. As we can see in the image, we have two elements at different heights, the one at a lower height rests on the ground. We must take this into account when assembling our render scene.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/08/Ground.jpg)
