# RhinoArtisan Layers

RhinoArtisan provides us with a new way to organize our elements. The new interface offers a new organization panel.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/08/Layers-3.png)

We can move different elements to different layers, as well as quickly hide or lock them using the new panel.

To do this, simply select the element to be changed and click on the assign arrow.

To set a layer as the active view, just select the desired color.

To lock, we will use the lock icon.

To hide or show elements, we will use the eye icon.
