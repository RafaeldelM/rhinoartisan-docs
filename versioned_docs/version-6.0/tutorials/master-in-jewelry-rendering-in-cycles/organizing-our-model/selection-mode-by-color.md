# Selection Mode: By Color

There is the possibility to select different elements that have the same color. For them we will use two methods:

**1.** We will write in the command bar SelColor, we will click on an element of the color that interests us, press enter.

**2.** We will click on the element of the color that interests us, we will write in the command bar SelColor, press enter.

**Example 1:**

As we see in the image, we have several models in a scene, each element has a different color. In this case we are interested in those that have red color. Select one of the diamonds, write SelColor, press enter.
