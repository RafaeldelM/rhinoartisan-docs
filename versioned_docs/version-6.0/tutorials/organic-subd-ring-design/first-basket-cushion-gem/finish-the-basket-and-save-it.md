# Finish the Basket and Save it

### Mirror Command

In the transform tab (1), use the **Mirror** command (2) from the **top View**:

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/mirrorCommand.png)

Mirror along the **Z-axis** for the upper section.

Mirror along the **Y-axis** for the lateral section.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/MirrorFinish.png)

### Save the basket

In the **file tab** (1), Open the **Curator Panel** (2).

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/CuratorPanelCommand.png)

Create a folder and name it appropriately.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Create-a-folder.png)

Add the basket and gem to the folder: Select both and click on **add**.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Create-a-folder-1.png)
