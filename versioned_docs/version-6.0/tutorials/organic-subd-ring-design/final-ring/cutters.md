# Cutters

### Create cutters

Navigate to the **Diamonds** tab and select the **Cutter** command.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Cutter.png)

Use the **Layer Panel** to select all gems by right-clicking their assigned color.

Add the gems to the cutter selector.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Cutter_add.png)

### Perform Boolean operations

* Go to the **Solid** tab and select **Boolean Difference**.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Boolean.png)

Select the baskets and press **Enter**.

Select the cutters and press **Enter** again.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/image-2024-11-20T175323.695.png)
