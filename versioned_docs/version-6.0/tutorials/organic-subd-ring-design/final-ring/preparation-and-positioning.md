# Preparation and Positioning

### Use Curator

Click on the baskets saved in **Curator** to add them to the viewport. If you already have the **Round Basket**, add only the **Cushion**.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Curatoradd-1.png)

### Group elements

* Select all elements of the cushion basket and group them using the **Group** command, type group in the command prompt and press enter.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Group.png)

* Repeat the grouping process for the round basket.

### Position the round basket

* Switch to **Wireframe View** in the **Front View**.
* Use the **Gumball** to align the round basket so its gem culet matches the cushion gem's culet. Hold **alt** to create a copy.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Align.png)

### Rotate Command

Rotate the round basket using the **Transform > Rotate** command.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Rotate.png)

Select **0** as the rotation axis and align using the **Project** option in **Osnap**.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/SubD-Proyect-History.png)

Ensure no overlap between the baskets.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/POSE-ROUND.png)
