# Apply Materials for Final Render

### **Ungroup the Elements**

Select the first ring, type `ungroup` in the command bar to separate the components of the model.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/12/ungroup.png)

### **Hide the Metals Layer**

Change the active layer and hide the **Metals** layer to focus on the gems.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/12/ungroup-1.png)

### **Apply Materials to Gems**

* Select all the lower gems of the first ring and apply the **Tourmaline Blue** material.
* Ungroup the gems of the second ring. Apply the **Citrine Orange** material to the main gem and **Tourmaline Rose** to the side gems.
* Ungroup the gems of the third ring. Apply **Topaz Violet** to the main gem and **Tanzanite Green** to the side gems.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/12/Materials.png)

### **Show Metals and Hide Gems**

* Reveal the metals layer and hide the gems to apply the metal materials.
* Select the metals and apply the **Rose Gold 18k** material to the entire metal layer.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/12/Metals.png)
