# Reference Curves

### **Curve Tab: Arc Command**

Go to the **Curve** tab and select the **Arc by Three Points** command.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Arc-3Points.png)

In the **Front View**:

* Place the first point slightly left of the gem along the **X-axis**.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/CURVE-REF.png)

* For the endpoint, count **three squares downward and one square toward the Z-axis**.
* Adjust the curve with the third point to achieve the desired shape.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/CURVE-REF2.png)
