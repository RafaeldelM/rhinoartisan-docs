# Second Bridge and Additional Prongs

### **Second Bridge**

Add a second bridge:

Use the Bridge command on additional faces between prongs.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/BRIDGE-FINAL.png)

Set Segment: 2 and repeat for each pair of prongs.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/BRIDGE-FINAL-SEGMENTOS.png)

We will do the same on the other side.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/finish_basket.png)

### Basket Properties

We select the basket and press **F3** to view its **properties**. As we can see, it is a **closed SubD**. With this, we have finished our second basket.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Group-45.png)

### Adjust the bridge

As we did earlier, we will lower the centers of the bridge. To do this:

* Select the two central points along with their edges.
* Follow the same procedure: first, lower the points and the edges

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Ajuste-1.png)

Then raise the points slightly to smooth the shape.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Ajuste-22.png)
