# Web 3D - Web Component

RhinoArtisan Web 3D is a client-ready jewelry visualization engine designed for modern web and application environments. Delivered as a Web Component and SDK, it can be embedded in any website or app with minimal setup, providing a reliable and consistent way to present jewelry designs in real time.

Web 3D works independently as a standalone visualization layer, but it truly shines when integrated with RhinoArtisan Connect. Through this integration, developers can connect visualization with configurators, backend logic, and AI-powered features such as recommendations, variants, and conversational experiences.

RhinoArtisan Web 3D is free to use, commercially allowed, and built to serve as the foundation for future jewelry experiences across web, apps, and in-store solutions.
