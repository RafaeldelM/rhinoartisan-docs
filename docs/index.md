# What is RhinoArtisan

<img src=".gitbook/assets/Logo-Artisan-with-icon-white (1).png" alt="" data-size="original"> &#x20;

RhinoArtisan is a cutting-edge, **parametric design software** tailored for goldsmiths and jewelry designers. Built as a Rhino plugin, it seamlessly integrates creative design with manufacturing precision, offering tools that adapt dynamically to design changes and production requirements.

One of RhinoArtisan’s standout features is its **parametric functionality**, which ensures that all elements of a design are interconnected and adapt automatically to modifications. For example:

* If a **gem set** is created for a round stone and the shape of the main stone is later changed, the gem set will adjust itself to fit the new gem shape perfectly.
* If a **ring** is designed and the size is altered, all associated parameters—such as profiles, gemstones, and settings—will automatically adapt to the updated size.

This adaptability eliminates the need for time-consuming manual adjustments and allows designers to iterate quickly and efficiently.

Other highlights include:

* **Manufacturing-Oriented Design**: Features like **Extension for Manufacturing** ensure production-ready designs by adjusting elements such as prongs for proper casting, while still allowing visualization of the final product during the design phase.
* **Dedicated Manufacturing Tools**: A specialized menu includes tools for adding sprues for smooth casting and preparing models for 3D printing, making the transition from design to production seamless.
* **Dynamic Customization**: Real-time previews, gumballs, and intuitive sliders allow for quick adjustments to dimensions, orientations, and other parameters.
* **Goldsmith's Perspective**: Practical workflows and industry insights ensure that every design is optimized for both aesthetics and functionality.

With its parametric core, RhinoArtisan empowers designers to experiment freely, knowing their designs will always remain cohesive and production-ready. It’s the ultimate tool for creating stunning, precise, and adaptable jewelry.
