# Socket Curve

In this lesson, we'll create the socket using a rounded rectangle.

### **Step 1: Top View**

Switch to the "Top" view for better precision. Double click

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Lesson-1-Curve-1024x576.jpg)

### **Step 2: Set the Layer Color**

Select a color from the left panel to visualize the curve.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/image-10.jpg)

### **Step 3: Rounded Curve Command**

Go to the "Curve" tab **(1)**, select "Rounded Rectangle" **(3)** in the "Rectangle"**(2)** section.

![](/img/v60/Rectangle Rounded.png>)

### **Step 4: COmmand Prompt Options**

In the "Command Prompt" options, choose "Center".

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Frame-1-1.png)

### **Step 5: Parameters**

In the Command Prompt:

* Enter `0` as the center point. Press **Enter**.
* Type `10 mm` for length. Press **Enter**.
* Type `1.5 mm` for width. Press **Enter**.
* Set the rounded corners to `1 mm`. Press **Enter**.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Frame-2.png)

The curve socket is now ready. Change to **Wireframe** mode to view the curve.

![](/img/v60/SocketCurve.png)
