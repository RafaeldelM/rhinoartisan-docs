# Create Pair

### **Step 1: Top View**

Now, click on the top view, at the top-left viewport, and we will create the pair for the earring.&#x20;

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/vlcsnap-2024-07-17-15h10m49s966.png)

### **Step 2: Pair Command**

In the **Rendering** tab, find and click on the **Pair** command to create a matching earring.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/08/Group-7221-2-1024x104.png)

### **Step 3: Create the Pair**

Select all the elements of your earring model. Press **Enter**.

In the command bar,:

* Set a distance of **25 millimeters** between the pair.
* For the pair’s angle, type **-45 degrees**.
* Mirror:  **No**

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-49-1024x595.jpg)
