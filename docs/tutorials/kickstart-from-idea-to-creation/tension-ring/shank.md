# Shank

### **Step 1: Cathedral**

Go to the "Shanks" tab and select the "Cathedral" command.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Tension-Ring-1-1024x170.jpg)

### **Step 2: Shanded Mode**

Switch to "Shaded Mode" in each viewport by selecting the option at the bottom right corner for better visualization.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-35-1024x574.jpg)

### **Step 3: Cathedral Library**

From the RhinoArtisan library, select model "007" **(1)** then click on edit **(2)**.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-37-1-1024x429.jpg)

### **Step 4: Parameters**

Go to the "Gems" tab **(1)** and deactivate the gems **(2)** to focus on the shank.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-40.jpg)

### **Step 5: Profile Assets**

Return to the "Shank Parameters," click on the profile curve, and change it to curve "022".

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-41-1-1024x480.jpg)

### **Step 6: Zoom Extents**

Center the views using "Pan, Zoom, and Rotate," followed by "Zoom Extents All."

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-42-1024x906.jpg)

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/image-1232-1024x556.png)

#### Next Steps

Adjust the shank parameters to refine the design.
