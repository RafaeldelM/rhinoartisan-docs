# Create a Collection

### **Step 1: Rotation**

From the "Top" view, select all elements and use the gumball to rotate 45 degrees.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/image-1239-1024x573.jpg)

### **Step 2: Pair**

Go to the "Rendering" tab and select the "Pair" command. Select the shank and the gems, press enter. In the command prompt type 15 milimiters for the distance, for the angle type 0.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-46-1024x656.jpg)

Create one more ring with a distance of -15 and the same angle.

> Note that if you right-click after using a command, it will execute again.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/image-1241-1024x459.jpg)

### **Step 3: Move**

Using the gumball, move the first ring 7 millimeters up, and the last one 7 millimeters down.<br>

<figure><img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/image-1242-1024x683.jpg" alt=""><figcaption></figcaption></figure>

Your ring collection is now ready for material application and rendering.
