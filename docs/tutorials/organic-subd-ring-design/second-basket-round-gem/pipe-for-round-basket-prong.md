# Pipe for Round Basket Prong

### **Pipe Command**

Navigate to the **Solid** tab and use the **Pipe** command.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/PipeCommand.png)

* Set **Output** to **SubD**.
* Select **Cap: Round**.
* Input a diameter of **0.6 mm** and press **Enter** twice.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Pipe_round.png)

### SubD Selection

Switch to the **SubD** tab (1):

Use **Face Selection Mode** (2).

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/SubD-FACE.png)

In the **Top View**, hold **Shift** and select the **four top faces** of the prong.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Face_round.png)

Click **Merge Faces** to combine them.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/SubD-merge-FACE.png)

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Pipe_merge.png)

### Adjust the prong shape

* Use the **Gumball** tool to proportionally scale down the selection by holding **Shift**. In the **Front View**, move the selection upward to create a pointed tip.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/scale_up.png)

* Position the prong tip toward the gem crown, aligning it to the gem center.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Place_pipe.png)
