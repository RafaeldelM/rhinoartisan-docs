# Bridges Between Baskets

### **Quick Polar Array**

In the transform tab, use **Quick Polar Array** to duplicate the round basket:

![](https://www.rhinoartisan.com/wp-content/uploads/2024/10/QuickPolarArray.png)

* Select the round basket.
* Set **Number of Copies: 6**, **Angle: 105 degrees**, and **Alignment: Left**.
* Leave gaps between baskets for bridging.

&#x20;

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/polararray.png)

> _If you can't properly visualize the model, remember to click the **Refresh** button to update the command parameters._
>
> ![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/image-33.png)

### Create bridges

To simplify the process, select the round baskets and move them to a different layer. To do this, click on the arrow in the **Layer** panel.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/layers.png)

In the **SubD** tab, use the **Bridge** command.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/SubD_Bridge.png)

Start with the cushion basket and select faces as shown in the image.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/REF-FACES-BRIDGE.png)

Repeat the process with the round basket.&#x20;

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/image-2024-11-20T170936.556.png)

Use the bottom view to facilitate the process

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/image-2024-11-20T171142.632.png)

Use **Segments: 2** for each connection.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/image-2024-11-20T171509.610-1.png)

Repeat the process with all the rounds baskets.&#x20;

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Bridges-finish.png)
