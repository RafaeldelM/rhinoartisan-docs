# Organic SubD Ring Design

### What You’ll Learn

<figure><img src="../../.gitbook/assets/Render (2).png" alt=""><figcaption></figcaption></figure>

**Basket Cushion Modeling**

* Learn how to define base curves for cushion baskets tailored to specific regions and sizes.
* Add cushion-shaped gems and align them perfectly.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/12/Group-50.png)

* Design and refine prongs using SubD geometry for precision and elegance.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/12/Group-51.png)

* Create connections between prongs and mirror them for symmetrical placement.
* Finalize cushion basket designs with high structural integrity.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/12/Group-52.png)

**Basket Round Modeling**

* Develop round gems and draw reference curves using advanced techniques.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/CURVE-REF.png)

* Design prongs for round baskets, ensuring symmetry and stability.
* Bridge prongs for added strength and refine connections for a flawless finish.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/BRIDGE-FINAL.png)

* Save and organize round basket designs for future use.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Curator.png)

**Advanced Basket Assembly**

* Align and connect multiple baskets for cohesive and intricate designs.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/layers.png)

* Create a classic shank to complement your baskets, adjusting dimensions for perfect fit.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/SolidClassic.png)

* Trim and refine materials based on ring size and design requirements.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Group-51.png)

**Cutting and Rendering Preparation**

* Generate cutters to expose gems and refine the overall design.
* Use Boolean operations to remove excess metal while maintaining structural balance.
* Transition seamlessly from SubD to NURBS for final refinements.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Cutter_add.png)

**Professional Rendering Setup**

* Prepare your model for stunning renders using high-quality material applications and lighting adjustments.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/12/Materials.png)



### What You’ll Need

**RhinoArtisan Software:** For creating intricate jewelry designs.

**SubD and NURBS Proficiency**: Basic familiarity is helpful but not mandatory—our step-by-step guides will walk you through each tool and technique.
