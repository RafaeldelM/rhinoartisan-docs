# Creating Copies Using the Gumball

### **Create the First Copy**

Select the ring model, then press **Alt** while using the **Gumball** to drag the copy upwards along the Z-axis.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/12/FirstCopie.png)

### **Position the Second Ring**

Rotate the second ring using the **Gumball** so that the basket cushion is positioned to one side of the first ring.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/12/PoseCushion.png)

Move the second ring slightly backward from the **Top View** to create separation between the two rings.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/12/PoseCushion2.png)

### **Adjust the Pose**

* The pose does not need to match the tutorial exactly. Feel free to position the second ring in a way that looks natural but does not overlap with the first ring for realistic rendering.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/12/PoseCushion3.png)
