# Reference Curve and Gem

### Reference Curve

Navigate to the **Shanks** tab (1) and select the **Curve** command (2).

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Shanks-Curve.png)

Set the region to **USA** and choose a **6 1/2** size.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Shanks-Curve-Parameters.png)

### Gem Studio

Navigate to the **Diamonds** tab (1) and select the **Gem Studio** command (2).

![](https://www.rhinoartisan.com/wp-content/uploads/2024/10/Gems-Studio.png)

* Choose **Shape: Cushion**.
* Set the size to **1.45 carats**.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Shanks-Diamond-Size.png)

### Adjust alignment

* Set **Vertical Alignment** to **Culet**.
* Move the gem in the Z-axis to **1.15 mm**.

&#x20;

Use the **Add Gem to Point** option and place the gem at the top of the previously created curve.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Shanks-Place.png)

Ensure the **Osnap** option is active to facilitate precise placement.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/OSnap.png)
