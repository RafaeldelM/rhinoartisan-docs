# The Toolbar

The **Toolbar** in KeyShot Studio is located at the top of the interface, providing quick access to key functions and tools. This area is designed to streamline the rendering process by offering shortcuts to essential features like the Library, Project settings, Animation tools, and rendering options. By mastering the Toolbar, jewelry designers can work more efficiently and focus on crafting stunning visuals.

<figure><img src="../../../.gitbook/assets/image (29).png" alt=""><figcaption></figcaption></figure>

![](https://manuals.keyshot.com/keyshot2024/Resources/Images/cloud_icon.png) **Cloud Library**\
Opens the Cloud Library window.

![](https://manuals.keyshot.com/keyshot2024/Resources/Images/import_icon.png) **Import**\
Opens the browse to file dialog to import scenes and 3D data into KeyShot Studio.

![](https://manuals.keyshot.com/keyshot2024/Resources/Images/library_icon.png) **Library**\
Opens the Library window.

![](https://manuals.keyshot.com/keyshot2024/Resources/Images/project_icon.png) **Project**\
Opens the Project window.

![](https://manuals.keyshot.com/keyshot2024/Resources/Images/timeline.png) **Animation**\
Opens the Animation Timeline and Animation Properties window. Note that Animation is a KeyShot Studio Pro feature.

![](https://manuals.keyshot.com/keyshot2024/Resources/Images/xr_icon.png) **KeyShotXR**\
Opens the KeyShotXR Wizard. Note that KeyShotXR requires the KeyShotWeb add-on to be installed, otherwise the icon will be disabled.

![](https://manuals.keyshot.com/keyshot2024/Resources/Images/configurator_icon.png) **Presentation**\
Enters full-screen Presentation Mode. This button is only displayed on the Toolbar for KeyShot Studio Pro users, if the Configurator has been set up in the scene.&#x20;

![](https://manuals.keyshot.com/keyshot2024/Resources/Images/vr_icon.png) **KeyVR**\
If you have KeyVR installed this button will bring your model into KeyVR with a single click.&#x20;

![](https://manuals.keyshot.com/keyshot2024/Resources/Images/render.png) **Render**\
Opens the Render window.&#x20;

![](https://manuals.keyshot.com/keyshot2024/Resources/Images/screenshot.png) **Screenshot**\
Takes a Screenshot of the Real-time view and saves it to your Renderings Resource Folder
