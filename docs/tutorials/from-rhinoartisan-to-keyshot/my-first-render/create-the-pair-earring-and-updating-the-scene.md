# Create the Pair Earring and Updating the Scene

**Objective:** Create a pair of earrings in RhinoArtisan and update the KeyShot scene.

**Create the Pair**

Now, without closing Keyshot, go back to RhinoArtisan.

* In the **Render tab**, click the **Pair button**.

<figure><img src="../../../.gitbook/assets/image (37).png" alt=""><figcaption></figcaption></figure>

* In the viewport, select the entire earring model.
* Press **Enter** to generate a duplicate with default spacing and rotation.

<figure><img src="../../../.gitbook/assets/image (38).png" alt=""><figcaption></figcaption></figure>

**Update the KeyShot Scene**

* Return to the **Render tab** and click the **Update Scene button**&#x20;

<figure><img src="../../../.gitbook/assets/image (39).png" alt=""><figcaption></figcaption></figure>

* In KeyShot, the scene will now display both earrings.

<figure><img src="../../../.gitbook/assets/image (40).png" alt=""><figcaption></figcaption></figure>
