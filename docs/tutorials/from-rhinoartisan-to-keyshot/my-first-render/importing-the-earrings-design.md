# Importing the Earrings Design

**Objective:** Learn how to import a 3D earring model from RhinoArtisan into KeyShot Studio for professional rendering.

### **Open the Earring Model**

**Download** the provided zip file that contains the necessary resources.



Open the **model** you just **downloaded**.

<figure><img src="../../../.gitbook/assets/image (31).png" alt=""><figcaption></figcaption></figure>

In the **Outliner panel**, you will see:

* A 0.50 ct diamond set in a basket.
* A 10 mm pearl supported by a metal base with an omega clip system, including the heel, post, and the omega itself.

<figure><img src="../../../.gitbook/assets/image (32).png" alt=""><figcaption></figcaption></figure>

**Layer Organization**

Different parts of the earring model are on separate layers:

* **Pearl**: Pink color in the viewport.
* **Diamond**: Orange color in the viewport.
* **Metal**: Includes the base and omega clip, which appear in a darker shade.



<figure><img src="../../../.gitbook/assets/image (33).png" alt=""><figcaption></figcaption></figure>

**Exporting to KeyShot Studio**

* Navigate to the **Render tab** in RhinoArtisan and click the **Live Linking button** (KeyShot icon).

<figure><img src="../../../.gitbook/assets/image (34).png" alt=""><figcaption></figcaption></figure>

* KeyShot Studio will open and import all visible elements in the viewport. Hidden elements in RhinoArtisan will not be imported.

<figure><img src="../../../.gitbook/assets/image (36).png" alt=""><figcaption></figcaption></figure>
