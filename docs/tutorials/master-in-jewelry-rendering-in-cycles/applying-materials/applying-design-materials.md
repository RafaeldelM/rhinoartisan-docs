# Applying Design Materials

If we want to apply a material to the created elements, just go to the Outliner tab, as we see in the image, it gives us the possibility to choose what color of gold we want. For diamonds and gems the color is applied automatically when created. In the case of having several models, we can apply different types of metal to each one, using the Hide/Show command, as we have seen in previous lessons we can hide or make visible different elements. Selecting a metal color will apply it to all visible items (Gems not included).
