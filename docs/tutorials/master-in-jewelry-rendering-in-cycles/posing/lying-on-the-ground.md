# Lying on the Ground

The **Lying on the Ground** command is a powerful tool that simplifies the process of positioning objects within your models. It automatically accounts for the perfect inclination to achieve balance along your chosen axis. Whether you're working with horizontally flat rings or other complex shapes, this command considers the specific needs of each model.&#x20;

1. Locate the "Lying on the Ground" command in the **rendering tab.**
2. Select the object you wish to position.&#x20;
3. If you want to position multiple objects, select them all simultaneously.
4. The "Lying on the Ground" command allows you to specify an axis along which the object will be positioned. Common axes include X, Y, and Z.
5. Select the axis that best suits your model's needs.
6. Once you have selected the object(s) and the axis, press enter.
7. RhinoArtisan will automatically calculate the perfect inclination and position your object(s) along the chosen axis.
