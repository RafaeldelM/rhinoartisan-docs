# Matching Properties

There are several properties that one element can obtain from another, within the properties menu, we find the option Match, this allows us to translate the selected properties.

Tip: In order to find the button Match we must have selected at at least one element.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/07-01.png) ![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/07-02.png)

&#x20;

**Example 1:**

In this case we want one of the diamonds in the yellow model to have the Material of the blue model. To do this:

**1.** We will select the diamond that we would like to be blue

**2.** In the properties menu press the Match button

**3.** We now select the element from which we will obtain the Material.

In the Match Properties panel we select the properties that we want to match. In this case Material. Press OK
