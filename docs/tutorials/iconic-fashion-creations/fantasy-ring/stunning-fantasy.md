# Stunning Fantasy

### **Step 1: Move**&#x20;

From the top view, use the Gumball to move the gem 4.5 millimeters on the X-axis.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Move-1024x349.png)

### **Step 2: Rotate Command**

Select both the gem and bezel. Use the "Rotate" command in the "Transform" tab.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Rotate-1024x175.png)

### **Step 3: Bezel Position**

Set the rotation center to point 0, using the XY plane. Type 0 in the command bar. Activate "Grid Snap" mode. Rotate 45 degrees by typing "45" into the command bar, ensuring the "Copy" option is set to "No."

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/image-16-1.png)

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Rotado-1024x1024.png)
