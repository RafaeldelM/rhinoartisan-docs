# Fashion Ring

In this tutorial, you’ll design a stylish ring featuring an oval gemstone in a bezel setting that allows light to pass through, enhancing the stone’s brilliance. We’ll craft a custom shank using profile curves and finish with material applications for a professional render.

<figure><img src="../../../.gitbook/assets/Render (July 02, 144224).png" alt=""><figcaption></figcaption></figure>

### What You’ll Learn

**Start with the Perfect Curve**\
Set up the ideal base curve to ensure a smooth, polished design.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Refcurves-1024x214.png)

**Gemstone Creation and Position with Precision**\
Choose an eye-catching 1.50-carat oval stone to be the focal point of the ring. Position the gem precisely to highlight its brilliance.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/GEm-0.35-1024x367.png)

**Add an Elegant Bezel Setting**\
Craft a bezel with optimal openings to allow maximum light flow through the gem.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Bezel_fashion-1024x401.png)

&#x20;

**Design the Custom Shank** \
Use the Profiles command to flow a beautiful, custom curve along the base. Adjust each curve to fit seamlessly with the ring’s style and proportions. Customize profile heights and widths for a comfortable, elegant fit.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Shank-2-1024x322.png)

**Apply Finishing Materials**\
Complete the look with a luxurious rose gold shank, white gold bezel, and a vibrant gemstone material.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Materiales-1024x306.png)

**Render a Beautiful Final Image**\
Set up a high-quality render to showcase your unique fashion ring in its best light.

<figure><img src="../../../.gitbook/assets/Render (July 02, 144224).png" alt=""><figcaption></figcaption></figure>

### Who Should Take This Course?

This course is ideal for CAD designers, jewelry artisans, or anyone looking to elevate their skills in 3D jewelry modeling. Whether you’re new to RhinoArtisan or looking to add engagement rings to your portfolio, this course will guide you through every step.

### Course Requirements

You’ll need RhinoArtisan software and a basic understanding of CAD commands. Each step is carefully explained, ensuring ease of following along regardless of experience level.
