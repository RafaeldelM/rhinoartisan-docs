# Pose and Save

### **Step 1**: Pose the Earrings

Type **Rotate** in the command bar, select both earrings, and choose the bottom point of the earring post as the base point. Select the bezel point that touches the **reference curve's tangent line**.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Rotate-1-1024x319.png)

### **Step 2**:  Orto

Press **Shift** or activate **Orto** to rotate the earring until it aligns with the **XY axis**.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Rotate_Orto-1024x319.png)

### **Step 3**: Save in the Curator Panel

Finalize the pose, and save the model in the **Curator** panel for future use.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Save_curator_Earring-1024x319.png)
