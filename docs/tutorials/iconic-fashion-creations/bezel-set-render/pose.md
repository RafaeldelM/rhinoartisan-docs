# Pose

### **Step 1**: Reference Image

Using a reference image, adjust the placement of the ring, earrings, and pendant in the viewport using the gumball tool.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Ref-image-First-1024x554.png)

### **Step 2:** Recreate **the Earrings**

* Ungroup the earrings by typing **Ungroup** in the command bar.
* Delete the left earring, go to the **Rendering,** use de **Pair** command and recreate the pair. Set the **Mirror** option and the angle to **0**. Position the earrings accordingly.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Ref-image-1024x554.png)

**Next Step**: Prepare the model for applying cutters and materials.
