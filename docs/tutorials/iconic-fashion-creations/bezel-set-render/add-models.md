# Add models

### **Step 1**: Use Curator

Go to the **Curator** panel and open the folder containing your collection.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Curator_Bezel-1024x576.png)

### **Step 2: The Ring**

Select the **ring** model, and group its elements by typing **Group** in the command bar. Position it on the left side of the viewport and rotate it **90 degrees** along the Z-axis.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Ring_rotation-1024x576.png)

### **Step 3: The Earring**

Add the **earrings**. Group it by typing **Group** in the command bar. Position the earrings on the right side of the viewport.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Earrrings_position-1024x576.png)

### **Step 4: The Pendant**

Add the **pendant** and group it as well.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Pendant_pose-1024x569.png)

### **Step 5: Align elements**

Switch to the **Right View**. Select all the models, type **Align** in the command bar, and choose the **Bottom** option.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Alinear-1024x362.png)

Type 0 and press Enter to align all elements along the YX axis at the same height.

**Next Step**: Move on to posing the models in the next lesson.
