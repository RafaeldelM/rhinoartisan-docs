# Create the Basket

### **Step 1: Basket Command**

In the "Diamonds" tab, select the gem and choose the **Basket** command.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Frame-1-5.png)

### **Step 2: Basket Library**

Choose the **BA014** basket model and press **Edit**.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Baskets.png)

### **Step 3:** Modify the following parameters:

* Set **Prongs** to **6**.
* Mode: **Circle**
* Diameter: Leave the default at **1.10 millimeters**.
* Height: **4 millimeters**
* Gem Inside: **0.35 millimeters**
* Over Girdle: **0.30 millimeters**
* Bottom Diameter: **1.1 millimeters**

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Baskets-1.png)
