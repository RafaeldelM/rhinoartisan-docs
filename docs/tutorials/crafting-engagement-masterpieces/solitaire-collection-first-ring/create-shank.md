# Create Shank



### **Step 1: Create de Shank**

Go to the "Shanks" tab and select the **Advanced** command.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-15.png)

### **Step 2: Advanced Library**

Choose model **006** and press **Edit**.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Shank-Advanced.png)

### **Step 3: Ring Size**

Adjust the size to **United States of America** and set the ring to **size 7**.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/image-17-1.png)

### **Step 4:  Shank Parameters**

Modify the following parameters:

* **Opening:** Set to **17.40 millimeters**
* **Height:** Set to **5.5 millimeters**
* **Width:** Set to **6.5 millimeters**
* **Move in Z:** Set to **0 millimeters**
* **Start on Circle:** Set to **1.57 millimeters**

&#x20;

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Shank-Advanced-1.png)

### **Step 9: Profiles**

In the **Profiles** tab, adjust:

* **Starting Cap:** Set to **2.30**
* **End Cap:** Set to **2.30**

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Shank-Advanced-2.png)

This ensures a better attachment between the basket and the shank.
