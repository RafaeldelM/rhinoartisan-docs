# Curator: Save

1. In the curator Panel, press Add Folder.
2. Name it  **"Solitaire Collection"**.
3. Select the first completed model, then press **"Add".**
4. Give the model a name (e.g., **"Solitaire Model 1"**).
5. Once saved in the Curator, you can safely delete this model from the workspace if needed.
