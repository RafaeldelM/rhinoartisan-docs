# Apply Materials

### **Step 1:  Render and Animation Panel**

Go to the "Render and Animation" panel.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-10-300x185.png)

### **Step 2: Gems Materials**

Select the gems and apply a "Diamond" material.

![](/img/v60/L5-Shank.png)

### **Step 3: Metals Materials**

Use the "Hide" command to hide the gems temporarily. Select the metals and apply an "18k White Gold" material.

![](/img/v60/L5-Shank-1.png)

### **Step 4:**  Ground Material

Use the "Show" command to reveal the gems again. Add a reflexion ground to display the ring elegantly.

![](/img/v60/L5-Shank-2.png)

**Next Step:** Pose the model for rendering.
