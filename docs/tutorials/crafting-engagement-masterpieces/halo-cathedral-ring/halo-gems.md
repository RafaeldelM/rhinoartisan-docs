# Halo Gems

### **Step 1:  Gems Parameters**

Go to the "Gems" tab in the halo settings and adjust the following parameters:

* Gem size: 1.80 millimeters.
* Min distance between gems: 0.20 millimeters.
* Inner width: 0.70 millimeters.
