# Prongs Settings

### **Step 1:  Prongs Settings**

In the "Prong Settings" tab, activate the third option (scalloped) and the "Boolean" option. Adjust the cutter parameters:

* Start width: 1.4 millimeters.
* End width: 0.4 millimeters.
* Mode: Independently.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-5-1.png)

&#x20;

### **Step 2: Cutters**&#x20;

In the V-Cuters section, adjust the length to 4 millimeters and activate the "V-Cuters " option.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-7-3.png)

### **Step 3:  Prongs**

Go to the "Prongs" tab and select the 4th option. Set the gem inside to 0.2 millimeters.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-8-1-1-383x1024.png)

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/image-12-1-1024x556.png)
