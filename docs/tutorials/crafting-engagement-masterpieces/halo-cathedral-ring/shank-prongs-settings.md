# Shank: Prongs Settings

### **Step 1: Prongs Settings**

In the "Prong Settings" section, activate the third option (scalloped) and the "Boolean" mode.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-15-1.png)

### **Step 2: Cutters**

Adjust the cutter Start width to 0.8 millimeters.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-16.png)

### **Step 3: V-Cutters and Drill**

Activate the "V-Prongs" mode. In the drill options, change the width of the Drill to 2 millimeters.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-18-1.png) ![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-17-1.png)
