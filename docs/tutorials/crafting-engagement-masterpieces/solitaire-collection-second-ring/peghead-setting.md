# Peghead Setting

### **Step 1: Gem Studio**

Select the gem and use the **Peg Head** command from the **Diamonds** tab.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-15-2-1024x138.png)

### **Step 2: Library**

Choose the **PE006** peg head element from the library in **RhinoArtisan**.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Peghead-1024x380.png)

### **Step 3: Parameters**

Press **Edit** and change the **orientation** of the prongs to **option 3.**

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Peghead2-1024x530.png)
