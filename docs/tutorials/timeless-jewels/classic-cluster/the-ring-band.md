# The Ring Band

### Cathedral Command

Now we’re moving on to the **Shank**, or the ring band.

Go to the **Shanks** (1) tab and select the Cathedral (2) command.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Cathedral-Command.png)

### Cathedral Library

We’ll start by selecting **element CA016**.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Cathedral-Shank.png)



### Profiles

Click on the **Profile preview** (1). In the **Asset Selector** (2), select profile **012**.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Asset-Selector.png)



### Finger Size

Adjust the size to **United States of America** and set the ring to **size 6 ½**.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/image-13.png)

### **Shank Parameters**

* **Top Width**: 1.83 mm
* **Top Height**: 2 mm
* **Bottom Width**: 3.05 mm
* **Bottom Height**: 1.7 mm

### **Cathedral Shank Parameters**

* **Width**: 9.53 mm
* **Height**: 2.3 mm
* **Angle**: 154º
* **Tangent**: 100%

### **Adjusting the Bridge**

* **Width**: 1.25 mm
* **Thickness**: 0.9 mm
* **Diameter**: 3.75 mm
* **Fillet**: 0

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Parameters-1.png)

These measurements give our band a graceful lift, creating space for the central gem while adding elegance to the design.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/FinishShank.png)

We set the bridge diameter to 3.75 mm to securely support the cluster base. This final adjustment ensures that the cluster is stable and well-balanced on the ring.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/MOdel-finish.png)
