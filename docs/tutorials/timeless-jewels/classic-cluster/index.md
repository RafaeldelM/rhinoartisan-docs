# Classic Cluster

### What You’ll Learn

**Create the Centerpiece**\
Start by crafting the cluster centerpiece—a brilliant 1-carat diamond. Set your scene with a clear visual by switching to the Shaded Display Mode for better clarity.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Place-Gems.png)

**Configuring Cluster** \
Set up gem parameters like spacing and positioning to create a balanced, classic look around the central gemstone.\
<br>

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/ClusterLibrary.png)

\
Configure the double-layered Gem Rail to hold gemstones securely and add style, adjusting dimensions for top and bottom rails.

**Configuring the Cluster Prongs**\
Adjust prong settings to securely hold gemstones in place while keeping alignment. Fine-tune parameters for size, spacing, and extension.\
<br>

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/PARAMETERS-cluster-prongs2.png)

**Configuring the Shank – The Ring Band**\
Use the Cathedral Shank style to elevate the central gem. Adjust dimensions and angle for a balanced, elegant ring band.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Cathedral-Shank.png)

**Adding and Adjusting the Bridge**\
Add a bridge to stabilize the cluster at the base, ensuring a secure, balanced design.<br>

<figure><img src="https://www.rhinoartisan.com/wp-content/uploads/2024/11/FinishShank.png" alt=""><figcaption></figcaption></figure>

**Cutters: Prepare the Gems and Metal**

Use _Cutters_ to remove metal that interferes with the gems, allowing light to interact properly.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Cutter_parameters.png)

**Final Steps Rendering**\
Review all elements and render the final Classic Cluster Ring design, ensuring each part fits perfectly.\
<br>

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/render2.png)

### Who Should Take This Course?

This course is ideal for CAD designers, jewelry artisans, or anyone looking to elevate their skills in 3D jewelry modeling. Whether you’re new to RhinoArtisan or looking to add engagement rings to your portfolio, this course will guide you through every step.

### Course Requirements

You’ll need RhinoArtisan software and a basic understanding of CAD commands. Each step is carefully explained, ensuring ease of following along regardless of experience level.
