# Solitaire Ring

### What You’ll Learn

**Create the Shank**\
Design the classic tapered shank using the **Classic Shank** command. Adjust profile, width, and height to your desired specifications.

<figure><img src="https://www.rhinoartisan.com/wp-content/uploads/2024/11/Profile-external-Result-1024x533.png" alt=""><figcaption></figcaption></figure>

**Design the Gem and Basket**\
Create a 1-carat diamond and place it in a custom basket. Modify parameters like height, diameter, and rail profiles for a perfect fit.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/ZoomExtents-1024x409.png)

**Apply Materials Rendering**\
Apply **White Gold 18k** to the ring and **Diamond** material to the gem. <br>

<figure><img src="https://www.rhinoartisan.com/wp-content/uploads/2024/11/White-GOld-1024x342.png" alt=""><figcaption></figcaption></figure>

**Rendering**

Set up the scene and render the design.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Render-1-1024x576.png)

### Who Should Take This Course?

This course is ideal for CAD designers, jewelry artisans, or anyone looking to elevate their skills in 3D jewelry modeling. Whether you’re new to RhinoArtisan or looking to add engagement rings to your portfolio, this course will guide you through every step.

### Course Requirements

You’ll need RhinoArtisan software and a basic understanding of CAD commands. Each step is carefully explained, ensuring ease of following along regardless of experience level.
