# Halo Setting

### **Step 1 - Halo command**

Select the main gem, navigate to the **Diamonds** tab (1), and click on the **Halo** command (2).

![](https://www.rhinoartisan.com/wp-content/uploads/2024/10/Halo-Command-1024x141.png)

Without selecting any elements, click Edit (1).

![](https://www.rhinoartisan.com/wp-content/uploads/2024/10/Halo-Setting-1024x278.png)

### **Step 2 - Set the parameters**

| Metal tab                                                                                         | Gems tab                                                                                                                                            | Prong Settings                                                                                                                            | Main gem's prong                                                      |
| ------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| <p>Width: 2.3 mm<br>Height: 1.5 mm<br>Distance to Gem: 0.1 mm<br>Z Position: 0, Rotation: 15°</p> | <p>Gem Size: 1.3 mm<br>Minimum Distance: 0.1 mm<br>Vertical Distance: 0 mm<br>Bright Cut: 0.1 mm<br>Inner Height: 0.7 mm<br>Inner Width: 1.2 mm</p> | <p>Option: second prong option<br>Gem Inside: 0.15 mm<br>Prong Height: 0.7 mm<br>Drill Shape: Round</p><p>Width &#x26; Height: 0.9 mm</p> | <p>Option: 4 Rotated Prongs<br>Mode: Circle<br>Gem Inside: 0.5 mm</p> |

&#x20;

![](https://www.rhinoartisan.com/wp-content/uploads/2024/10/Parametros-1024x555.png)

### **Step 3 - Confirm all changes**

Click “Confirm” to save all changes.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/10/Halo-FInal-1024x543.png)
