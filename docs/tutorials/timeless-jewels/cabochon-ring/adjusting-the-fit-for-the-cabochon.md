# Adjusting the Fit for the Cabochon

### **Move the Cabochon**

In the front view, use the gumball to move the cabochon 0.7 mm down.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/MoveCabochon.png)

### **Offset Surface**

* Select the cabochon, then type **Offset** in the command bar.
* Use the arrow keys to select **Offset Surface**.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/OffsetSrf.png)

* Set the **Distance** to **0.05 mm**.
* Press **Enter** to create the offset.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/OffsetSrfParametros.png)
