# Edge Softening, Material Application and Rendering

### **Edge Softening**

* Select the **shank** and press **F3** to access properties.
* In the **Edge Softening** tab, set **Softening** to **0.2** and click **On** to activate.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Propiedades.png)

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Soft.png)

### **Material Application**:

* Go to the **Render and Animation** panel.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Render.png)

* Apply **Rose Gold 18k** to the shank.
* For the cabochon, select a **Ruby material**.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Materials.png)

### Render Settings

**Set Perspective and Render Settings**:

* Adjust the **perspective angle** and **distance** to best showcase the ring.
* Set your preferred **Resolution** and **Quality** parameters.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/REnder_cabochon.png)

Click the **Render** button to produce the final image.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/11/Render-4k.png)
