# Copies

## <img src="../../.gitbook/assets/COPIES.png" alt="" data-size="line"> Copies

The **Copies** tool is designed to streamline the process of creating duplicates of imported STL files, enabling efficient preparation for manufacturing tasks such as 3D printing.

#### Features:

1. **Object Selection**:
   * Prompts users to select the objects from which copies will be created.
2. **Copy Count Input**:
   * Users specify the exact number of copies needed for each selected object.
3. **Y-Axis Distribution**:
   * Automatically distributes the created copies along the Y-axis, ensuring a clear and organized layout.

#### Advantages:

* **Enhanced Flexibility**: Provides precise control over the number of duplicates required, catering to diverse manufacturing needs.
* **Improved Organization**: By distributing copies along the Y-axis, the tool prevents overlapping and maintains a clean workspace.
* **Integrated Workflow**: Complements the **Distribute** tool, enabling users to prepare print trays with ease and precision.

The **Copies** tool is an essential addition for professionals aiming to optimize their workflow by automating the duplication and arrangement of STL files within their projects.
