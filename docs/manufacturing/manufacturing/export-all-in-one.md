# Export All in One

## <img src="../../.gitbook/assets/MENU_MOVE.png" alt="" data-size="line"> Export All in One

The **Export All in One** command allows you to export everything arranged on your printer tray into a single file. This ensures you can easily recover the entire layout for future printing sessions without needing to rearrange or reconfigure the setup.

**Benefits**

* Saves time by preserving the exact arrangement of objects for reuse.
* Simplifies workflow for repetitive printing tasks by consolidating the setup into one file.
