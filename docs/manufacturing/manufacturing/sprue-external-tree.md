# Sprue External Tree

## <img src="../../.gitbook/assets/3DPRINTING_EXTERNAL_BRANCHES.png" alt="" data-size="line"> Sprue External Tree

The **Sprue External Tree** command is especially useful for placing the sprue in designs with intricate details on both the front and back of the piece, such as a pavé design with a backing. This command helps create external structures that ensure proper support and metal flow during the casting process.

<figure><img src="../../.gitbook/assets/image (136).png" alt=""><figcaption></figcaption></figure>

#### **Command Structure**

**Selection Panel**

* **Mesh Selection**: Select the mesh where you want to place the sprues.
* **Main Branch Starting Point**: A selector to define the point on the mesh where the main branch will begin.

**Parameters Panel**

1. **Main Branch Height and Diameters**:
   * Define the **height** of the main branch and its **upper** and **lower** diameters.
2. **Add Branches**:
   * Use the button to add secondary branches by selecting the point on the mesh where each branch will terminate.
   * To delete all the branches click on the Delete button.
   * To delete a specific branch, hold down the **Shift** key and click on the branch's gumball. This action will immediately remove the selected branch.
3. **Branch Diameters**:
   * Define the diameters of the secondary branches at both the contact point with the main branch and the contact point with the mesh of your design.

<figure><img src="../../.gitbook/assets/image (702).png" alt="" width="269"><figcaption></figcaption></figure>

The **Sprue External Tree** allows precise placement of sprues with customizable diameters and branch points, ensuring delicate details remain intact. The command saves time, enhances symmetry for designs, and reduces casting defects, resulting in higher-quality pieces.
