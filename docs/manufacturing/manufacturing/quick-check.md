# Quick Check

## <img src="../../.gitbook/assets/QUICK_CHECK (2).png" alt="" data-size="line"> Quick Check

The **Quick Check** tool ensures that STL files are error-free and ready for 3D printing, providing a fast and reliable way to verify file integrity.

#### Features:

1. **Mesh Verification**:
   * Prompts users to select the meshes they want to verify.
   * Checks for errors in the STL file's construction.
2. **Visual Feedback**:
   * Displays error-free meshes in green for immediate recognition.
   * Highlights problematic meshes in red, making it easy to identify issues.
3. **Error Repair Integration**:
   * In case of errors, users can directly employ the **Automatic Repair STL** command to resolve issues and ensure the mesh meets 3D printing standards.

<figure><img src="../../.gitbook/assets/Visual Error Detection.png" alt=""><figcaption></figcaption></figure>

#### Advantages:

* **Error Prevention**: Identifies problematic STL files early in the process, reducing the risk of failed prints.
* **Visual Feedback**: Provides instant, clear visual feedback on the status of the selected meshes, streamlining the verification process.
* **Integrated Workflow**: Works seamlessly with the other tools in the Manufacturing section, ensuring a smooth transition from file preparation to final checks.

The **Quick Check** tool is a vital resource for professionals aiming to maintain the highest quality standards in 3D printing, ensuring that only error-free STL files proceed to the manufacturing stage.
