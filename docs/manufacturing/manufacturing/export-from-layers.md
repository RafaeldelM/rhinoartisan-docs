# Export from Layers



## <img src="../../.gitbook/assets/MENU_MOVE-1.png" alt="" data-size="line"> Export from Layers



The **Export From Layers** command is useful for saving the STL files arranged on the printer tray using the **Preload** command. It allows you to export the copies from each layer into a single file, making it easier to manage and organize for future repetitive printing tasks.

**Benefits**

* Simplifies the management of repeated prints.
* Ensures that all necessary files are grouped by layers, streamlining the workflow for subsequent printing sessions.&#x20;
