# Dual Pear Diamond Ring

Welcome to RhinoArtisan!
\
In this tutorial, we’ll model a sleek pear-set ring from scratch using a fully parametric workflow. We’ll start with a Spanish size 14 ring curve and build a precise shank with reusable profiles. Then we’ll place a 5×8 mm pear-cut center stone, construct a custom straight-prong basket, carve elegant side channels, add a graded pavé, finish with delicate millgrain, mirror the detailing, and prepare clean cutters for production and rendering.

📌 What You’ll Learn:
\
✔ Designing a three-stone engagement ring from scratch
\
✔ Building a smooth shank
\
✔ Creating accurate seats for princess and trillion-cut stones
\
✔ Customizing prongs and supports for secure stone setting
\
✔ Applying Boolean operations for clean manufacturing geometry
\
✔ Optimizing the structure for strength and ergonomic comfort
\
✔ Preparing a full jewelry CAD for rendering or production
