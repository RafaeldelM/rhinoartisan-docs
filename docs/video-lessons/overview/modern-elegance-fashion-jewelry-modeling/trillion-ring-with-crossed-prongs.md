# Trillion Ring with Crossed Prongs

Welcome to RhinoArtisan! In this tutorial, we’ll walk through a complete, production-focused workflow for creating an elegant **classic shank ring with a trillion-cut center stone and crossed prongs**. Starting from a precise shank curve, you’ll learn how to position and orient the main gem, design custom SubD crossed prongs, and integrate side stones seamlessly into a clean, traditional shank.

Throughout the process, we’ll combine curve-based construction, SubD modeling, and surface workflows to ensure the ring remains structurally sound, visually balanced, and fully manufacturing-ready. The tutorial continues with gemstone placement along the shank, detailed cutter configuration, pavé refinement on the prongs, and finishes with a secure basket for the center stone and final boolean operations — resulting in a polished model ready for rendering or production.

📌 **What You’ll Learn:**\
✔ Creating a precise classic shank curve by size and region\
✔ Positioning and orienting a trillion-cut center stone using Gem Studio\
✔ Designing crossed SubD prongs using Blend curves and Pipes\
✔ Advanced SubD editing: edge loops, bridges, symmetry, and smoothing\
✔ Building and refining a clean classic shank using Sweep 1 Rail\
✔ Using History to dynamically adjust and customize the shank profile\
✔ Placing side stones along the shank with Gems on Curve\
✔ Configuring micro cutters, V-cutters, and rails for secure stone settings\
✔ Adding pavé stones on prongs and refining gem heights manually\
✔ Creating and editing a custom basket for the center stone\
✔ Final boolean operations for a clean, production-ready model

📢 **Why Watch This?**\
✅ Learn a complete classic shank ring workflow from start to finish\
✅ Master crossed prong construction for elegant and secure center stones\
✅ Combine SubD flexibility with precise curve and surface control\
✅ Build optimized geometry ready for 3D printing and casting\
✅ Improve efficiency using RhinoArtisan’s specialized jewelry tools
