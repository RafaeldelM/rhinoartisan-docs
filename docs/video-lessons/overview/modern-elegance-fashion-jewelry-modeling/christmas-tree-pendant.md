# Christmas Tree Pendant

Welcome to RhinoArtisan! In this in-depth tutorial, we’ll guide you step by step through the complete process of designing a complex pavé-set pendant using RhinoArtisan. Starting from reference curves and surface construction, you’ll learn how to build clean, production-ready geometry, create multiple pavé rails, place gemstones with precision, and refine the model with baskets, bezels, cutters, and prongs.

This tutorial covers both technical accuracy and creative decision-making, showing how to control topology, manage symmetry, and combine different stone-setting techniques into a single, cohesive jewelry design. By the end, you’ll have a fully finished pendant model, optimized for manufacturing and ready for rendering.

📌 **What You’ll Learn:**\
✔ Preparing and organizing reference curves for complex jewelry construction\
✔ Creating surfaces using Network, Loft, and Sweep 2 Rails\
✔ Building structured pavé rails with precise offsets and Push & Pull\
✔ Managing surface topology for optimal pavé distribution\
✔ Placing gems using Gems on Curve, Pavé Along Surface, and Manual Pavé\
✔ Creating and customizing baskets, bezels, and custom rail profiles\
✔ Using symmetry, arrays on curve, and orientation surfaces efficiently\
✔ Adding prongs and cutters with manufacturing-ready parameters\
✔ Final boolean operations and detailing for a clean production model

📢 **Why Watch This?**\
✅ Learn an advanced, real-world pendant workflow from start to finish\
✅ Understand how to control topology for better pavé results\
✅ Combine multiple stone-setting styles in one professional design\
✅ Build clean, optimized geometry suitable for 3D printing and casting\
✅ Improve speed and precision using RhinoArtisan’s specialized jewelry tools
