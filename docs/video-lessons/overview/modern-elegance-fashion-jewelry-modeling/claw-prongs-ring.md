# Claw Prongs Ring

In this in-depth tutorial, we demonstrate how to model a complete multi-stone ring using RhinoArtisan’s specialized jewelry design tools. Starting with a reference curve based on ring size, we guide you through placing a central round gemstone, adding and positioning smaller stones along a custom shank, and creating precise prong settings using the Basket tool.

You’ll also learn how to use commands like Gem Studio, Advanced Gems on Curve, Apply Element, and Quick Flow to build a clean, manufacturable model. The tutorial ends with adjustments to finalize the ring’s size and fit, ensuring it meets professional jewelry standards.

Whether you're a CAD designer, bench jeweler, or student, this tutorial will help you deepen your understanding of gemstone layout, curve-based modeling, and advanced setting techniques in RhinoArtisan.

📌 **What You’ll Learn:**\
✔ How to position gemstones using the Gem Studio and Advanced Gems on Curve tools\
✔ How to generate accurate basket settings and customize prongs using the Basket command\
✔ How to use Apply Element to adapt settings to multiple stones\
✔ How to build a clean ring shank using curve trimming, profiles, and surface projection\
✔ How to finish your model to the correct ring size using Cut by Ring Size
