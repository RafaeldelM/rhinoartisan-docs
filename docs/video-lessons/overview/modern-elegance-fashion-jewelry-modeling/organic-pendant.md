# Organic Pendant

**Welcome to RhinoArtisan!** In this step-by-step tutorial, we’ll guide you through modeling an organic pendant with custom profiles and gemstone settings using RhinoArtisan’s advanced tools. This video is perfect for jewelry designers and CAD artists looking to create fluid, elegant structures ready for production or high-quality rendering.

📌 **What You’ll Learn:**\
✔ Using reference surfaces and Project Osnap for precise alignment\
✔ Creating and editing custom profiles along complex curves\
✔ Applying elements to curves with full control over width, height, and flow\
✔ Positioning gemstones organically with accurate carat sizes\
✔ Designing advanced settings like baskets and bezels for various stone shapes\
✔ Fine-tuning geometry for clean intersections and realistic presentation

📌 **Tools Used in This Video:** RhinoArtisan\
📌 **Techniques:** Apply Element, Profiles, Basket, Bezel, Gumball Alignment, Surface Projection, Organic Stone Placement
