# Scatter Ring Design

Welcome to RhinoArtisan!

In this tutorial, we’ll guide you step by step through modeling a complex multi-stone ring using RhinoArtisan’s powerful jewelry design tools. You’ll learn how to create a central cushion-cut gemstone, add and arrange various stone shapes like rounds, baguettes, and marquises, and build precise settings using tools like Basket, Apply Element, and Quick Flow.

This tutorial is perfect for jewelers, CAD professionals, or anyone looking to improve their digital craftsmanship in RhinoArtisan.<br>

📌 What You’ll Learn:

✔ How to create and arrange multiple gemstone types using the Studio tool

✔ How to align and scale reference images for accurate modeling

✔ How to use Basket and Apply Element to generate custom prong settings

✔ How to fit elements onto a ring shank using Quick Flow and Curve tools

✔ How to finalize the ring with precise size adjustment using Cut by Ring Size<br>

✅ Learn real-world gemstone setting workflows used in jewelry production
