# Oval Halo Setting Ring

Welcome to RhinoArtisan! In this tutorial, we’ll guide you through a complete, production-ready workflow to build an **oval center stone setting with detailed rails, pavé accents, and carved galleries**, finished with a **classic shank**. You’ll start by creating the oval gemstone in Gem Studio, extracting clean reference curves, and building a fully symmetrical design using offsets, arcs, blends, and curve optimization.

From there, you’ll construct the setting with **Sweep 2 Rails**, generate precise rails using surface extraction and controlled booleans, and refine/close the solid with merge operations and loft repairs. We’ll then place gemstones using curve-driven distribution and pavé tools, add prongs and cutters with manufacturing parameters, and finish with a custom basket for the center gem. Finally, you’ll carve elegant **galleries** using boolean difference and boolean intersect techniques for a clean, professional result ready for rendering or production.

📌 **What You’ll Learn:**\
✔ Creating an oval gemstone (1.5 ct) in Gem Studio and extracting the Gem Curve\
✔ Building a symmetrical halo layout using offsets, divide by segments, and tangent arcs\
✔ Creating smooth transitions with Blend curves, joining, fillet corners, and curve fitting\
✔ Enforcing perfect symmetry using Trim + Mirror Quad reconstruction\
✔ Positioning the setting relative to the gem and ring size curve (US 6.5 reference)\
✔ Building the main setting volume with **Sweep 2 Rails** and closed seam control\
✔ Forming rails via structure surface extraction, splits, offsets, and boolean difference\
✔ Repairing and closing geometry using merge edges and lofts for watertight solids\
✔ Extracting isocurves and preparing curve networks for consistent gem distribution\
✔ Placing stones with **Gems by Curve** and fine-tuning spacing and alignment\
✔ Adding prongs and cutters with controlled diameters and clearances\
✔ Completing center opening stones using Pavé + mirrored placement workflows\
✔ Creating a custom basket for the center oval (6 claws + rail adjustments)\
✔ Building a classic shank with editable profiles and trimming via boolean difference\
✔ Carving clean galleries using extruded cutting curves + boolean difference/intersect

📢 **Why Watch This?**\
✅ Learn a full setting workflow: design curves → build solids → rails → stones → galleries\
✅ Master symmetry and curve control for clean, repeatable professional results\
✅ Create watertight, manufacturing-ready geometry optimized for production\
✅ Combine curve-based gem placement with pavé detailing and prong control\
✅ Use RhinoArtisan booleans to carve refined galleries with clean topology
