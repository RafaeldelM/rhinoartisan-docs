# Interwoven Pavé Pendant

Welcome to RhinoArtisan! In this tutorial, we’ll guide you step by step through the process of creating a **cocktail-style pavé pendant** using RhinoArtisan’s powerful jewelry CAD tools. Starting from basic curves and surfaces, we’ll build the main structure, generate decorative patterns using surface flow techniques, and create recessed areas ready for pavé stone setting.

You’ll learn how to project curves onto complex surfaces, control depth with push-and-pull operations, and prepare the model for gemstone placement. Finally, we’ll explore different pavé workflows — both manual and automatic — and complete the piece by adding prongs, a bail, and a loop for the pendant. The result is a clean, production-ready jewelry model ready for rendering or manufacturing.&#x20;

### 📌 What You’ll Learn:

✔ Creating the base geometry using curves, arcs, and sweep surfaces\

✔ Projecting curves onto complex surfaces for accurate modeling\
✔ Controlling relief depth using Push & Pull operations\
✔ Preparing surfaces for pavé gemstone placement\
✔ Using manual and automatic pavé tools to place diamonds efficiently\
✔ Generating automatic prongs and refining them manually\
