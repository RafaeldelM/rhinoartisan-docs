# Emerald Chandelier Earrings

Welcome to RhinoArtisan! In this tutorial, we’ll walk through a complete, production-ready workflow for creating **Indian-inspired earrings** featuring **bezels, baskets, pear-shaped gemstones, and secure structural connections**. Starting from an existing design and reference image, you’ll learn how to refine gemstone sizes, standardize bezels across multiple stones, and carefully balance proportions for an elegant, wearable result.&#x20;

We’ll cover advanced bezel editing, basket customization, rail adjustments, and solid connections to ensure all elements are structurally sound. The tutorial finishes with the creation of fixing pipes, symmetry-based optimization, and the integration of a professional **earring post and push**, resulting in a fully finished pair of earrings ready for rendering or manufacturing.
