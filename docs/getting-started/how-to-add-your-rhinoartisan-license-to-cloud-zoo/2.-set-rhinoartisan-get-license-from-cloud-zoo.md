# 2. Set RhinoArtisan Get License from Cloud Zoo

:::info
This documentation assumes you have set up your Cloud Zoo with your Rhino licenses. If you haven’t done so, please refer to the [Cloud Zoo Licensing Setup link](https://www.rhino3d.com/features/administration/licensing/).
:::

In RhinoArtisan, in the "File" tab, click on "Settings".

<figure><img src="../../.gitbook/assets/image (169).png" alt=""><figcaption></figcaption></figure>

If you use RhinoArtisan within Rhino, click on the **Options** icon or type the **Options** command.

<figure><img src="../../.gitbook/assets/image (168).png" alt=""><figcaption></figcaption></figure>

The Rhino options will appear; select **Artisan** from the list, then check the option to **Enable the license through Cloud Zoo,** and click on the OK button.

<figure><img src="../../.gitbook/assets/image (170).png" alt=""><figcaption></figcaption></figure>

:::info
Does the license option not appear? Then, you need to download a new version at [www.rhinoartisan.com/dashboard/download](http://www.rhinoartisan.com/dashboard/download).
:::

It will ask us to close RhinoArtisan (or Rhino).

<figure><img src="../../.gitbook/assets/image (171).png" alt=""><figcaption></figcaption></figure>
