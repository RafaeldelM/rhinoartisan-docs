# Display

## <img src="../../.gitbook/assets/G1_03_SUBD_DISPLAY_MODE.png" alt="" data-size="line"> Display <a href="#profiles" id="profiles"></a>

The SubDDisplayToggle command switches the appearance of all [SubD objects](https://docs.mcneel.com/rhino/8/help/en-us/seealso/sak_subd.htm) between smooth and flat modes.

<div align="left"><img src="https://docs.mcneel.com/rhino/8/help/en-us/image/topic_illustrations/subddisplaytoggle.gif" alt=""></div>

### **Steps**

* Press Tab.
* The Tab key does not toggle SubD display while you are picking a direction in commands because, at this point, the Tab key is used for locking a direction. To toggle SubD display while picking a direction, click <img src="../../.gitbook/assets/G1_03_SUBD_DISPLAY_MODE.png" alt="" data-size="line"> on the [SubD Tools](https://docs.mcneel.com/rhino/8/help/en-us/toolbarmap/subd_tools_toolbar.htm) toolbar, or map the SubDDisplayToggle command to a key (e.g., F4) in Tools > Options > Keyboard and use it.

The SubDDisplayToggle command:

* Is nestable (can be run while other commands are running).
* Does not change object selection states.

For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/subddisplaytoggle.htm?Highlight=SubDDisplay).
