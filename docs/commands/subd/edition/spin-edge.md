# Spin Edge

## <img src="../../../.gitbook/assets/G5_07_SPIN_EDGE.png" alt="" data-size="line"> Spin Edge

The SubDSpinEdge rotates a picked SubD edge by marching each end to the next vertex simultaneously.

<div align="left"><img src="https://docs.mcneel.com/rhino/8/help/en-us/image/topic_illustrations/subdspinedge.gif" alt=""></div>

**Steps**

1. Pick a SubD edge.
2. Use the SpinEdgeAgain option to spin the same again, or pick another edge.
3. Press Enter to exit the command.

For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/subdspinedge.htm?Highlight=Spin%20Edge).
