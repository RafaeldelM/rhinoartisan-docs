# RepairSubD

## <img src="../../../.gitbook/assets/G7_02_SUBD_REPAIR_MESH.png" alt="" data-size="line"> RepairSubD <a href="#profiles" id="profiles"></a>

The RepairSubD command inspects and deletes damaged components, wire edges, and Non-manifold edges on SubDs.

<div align="left"><img src="https://docs.mcneel.com/rhino/8/help/en-us/image/topic_illustrations/repairsubd.gif" alt=""></div>

### Command-line options

#### **DamagedVertex=Delete/Keep**

Deletes or keeps damaged vertices.

#### **WireEdge=Delete/Keep**

Deletes or keeps wire edges.



For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/repairsubd.htm#\(null\)).
