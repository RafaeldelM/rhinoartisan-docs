# RemoveSymmetry

## <img src="../../../.gitbook/assets/SUBD_REMOVE_SYMM.png" alt="" data-size="line"> RemoveSymmetry <a href="#profiles" id="profiles"></a>

The RemoveSymmetry command removes the SubD symmetry constraints set by the Reflect and Radiate commands from selected SubDs.



For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/subd_symmetry_commands.htm#RemoveSymmetry).
