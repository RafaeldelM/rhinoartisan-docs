# Ellipse

### <img src="../../../.gitbook/assets/G1_07_DRAW_ELLIPSE.png" alt="" data-size="line"> Ellipse

Draw a closed elliptical curve from center and edges.

### <img src="../../../.gitbook/assets/ELLIPSE_01_DRAW_DIAMETER.png" alt="" data-size="line"> Diameter

Draws a closed elliptical curve by diameter.

### <img src="../../../.gitbook/assets/ELLIPSE_02_DRAW_FROM_FOCI.png" alt="" data-size="line"> From Foci

Draw a closed elliptical curve from focus points.

### <img src="../../../.gitbook/assets/ELLIPSE_03_DRAW_AROUND_CURVE.png" alt="" data-size="line"> Around Curve

Draw a closed elliptical curve around a curve.

### <img src="../../../.gitbook/assets/ELLIPSE_04_DRAW_CORNER.png" alt="" data-size="line"> By Corners

Draw a closed elliptical curve from bounding rectangle.

### <img src="../../../.gitbook/assets/ELLIPSE_05_DRAW_DEFORMABLE.png" alt="" data-size="line"> Deformable

Draw a closed elliptical NURBS approximation of the curve will be created with the number of points you specify.
