# Curve

### <img src="../../.gitbook/assets/G1_03_DRAW_CURVE.png" alt="" data-size="line"> Curve

Draw a curve from [control point](https://docs.mcneel.com/rhino/8/help/en-us/popup_moreinformation/controlpoint.htm) locations.

### <img src="../../.gitbook/assets/CURVE_01_DRAW_CONTROL_POINTS.png" alt="" data-size="line"> Control Points

Fit a curve through picked locations.

### <img src="../../.gitbook/assets/CURVE_02_DRAW_TO_POLYLINE.png" alt="" data-size="line"> Control Points From Polyline

Builds a curve using the control points of a polyline

### <img src="../../.gitbook/assets/CURVE_03_DRAW_HANDLE.png" alt="" data-size="line"> Handle Curve

Draw chained Bézier curves with editing handles.

### <img src="../../.gitbook/assets/CURVE_04_DRAW_SKETCH.png" alt="" data-size="line"> Sketch

Drag the mouse to draw a curve.

### <img src="../../.gitbook/assets/CURVE_05_DRAW_SKETCH_SRF.png" alt="" data-size="line"> Sketch On Surface

Drag the mouse to draw a curve on a selected surface.

### <img src="../../.gitbook/assets/CURVE_06_DRAW_SKETCH_MESH.png" alt="" data-size="line">Sketch On Mesh

Drag the mouse to draw a curve on a selected mesh.

### <img src="../../.gitbook/assets/CURVE_07_DRAW_CONIC.png" alt="" data-size="line"> Conic

The Conic command draws a conic section curve based on a start, end, and apex point.

### <img src="../../.gitbook/assets/CURVE_08_DRAW_CONIC_TANGENT.png" alt="" data-size="line"> Conic: Tangent At Start

Lets you select a curve for the conic curve to be tangent to for the start or end of the conic.

### <img src="../../.gitbook/assets/CURVE_09_DRAW_PARABOLA.png" alt="" data-size="line">Parabola From 3 Points

Draw a parabolic curve through three picked points.

### <img src="../../.gitbook/assets/CURVE_10_DRAW_PARABOLA_FOCUS.png" alt="" data-size="line"> Parabola By Focus

Draw a parabolic curve from focus and vertex or endpoint.

### <img src="../../.gitbook/assets/CURVE_11_DRAW_HYPERBOLA.png" alt="" data-size="line">Hyperbola

The Hyperbola command draws a hyperbolic curve.

### <img src="../../.gitbook/assets/CURVE_12_DRAW_CATENARY.png" alt="" data-size="line"> Catenary

Creates a curve that a hanging chain or cable assumes under its own weight when supported only at its ends.
