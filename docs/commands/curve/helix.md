# Helix

## <img src="../../.gitbook/assets/G1_13_DRAW_HELIX (1).png" alt="" data-size="line"> Helix



The **Helix** command in Rhino creates helical curves with several customization options. Key command-line features include:

* **Vertical**: Creates a helix with an axis perpendicular to the construction plane.
* **AroundCurve**: Draws a helix around a selected curve.
* **Diameter/Radius**: Toggle between radius and diameter input.
* **Turns**: Defines the number of turns; pitch adjusts automatically.
* **Pitch**: Defines the distance between turns; number of turns adjusts automatically.
* **ReverseTwist**: Reverses the direction of the helix twist.

These options are useful for designing components such as coiled jewelry, springs, or threaded elements.
