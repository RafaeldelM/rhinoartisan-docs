# Raster to Vector

## <img src="../../.gitbook/assets/G2_06_DRAW_IMAGE_TO_VECTOR.png" alt="" data-size="line"> Raster to Vector

This command converts an image into a group of curves. It's handy for translating images into 3D models.

The command's parameters will be displayed on the Commands toolbar.

![](/img/v60/Raster to vector.jpg>)

Select an image in any format, and a preview will be displayed. Using the available parameters, you can define how you want the curves to adapt to the image and whether you want to smooth sharp edges.
