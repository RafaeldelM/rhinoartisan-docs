# Flip Direction

## <img src="../../../.gitbook/assets/ANALYZE_FLIP.png" alt="" data-size="line"> Flip Direction

The Flip command reverses the normal direction of an object.

### **Supported input objects**

* Curve, surface, polysurface, mesh, SubD, Clipping Plane and rectangle light.

### **Steps**

* Select objects.

\
The command line reports the number of objects flipped.

For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/flip.htm).
