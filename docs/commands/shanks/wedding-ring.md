# Wedding ring

## <img src="../../.gitbook/assets/RIBBON_SHANK_WEDING.png" alt="" data-size="line"> Wedding Ring

The **Wedding Rings** command is designed to create two wedding bands for the couple, offering customization options for each ring individually. This command consists of a **Parameters Panel**, divided into two tabs: one for each ring.

<figure><img src="../../.gitbook/assets/image (127).png" alt=""><figcaption></figcaption></figure>

#### Key Features:

* **Ring Size & Profile**:\
  In each tab, you can define the **size** of the ring and choose the **profile** that will be used to create the ring. You also have the option to modify the shape of the profile if needed, with adjustable settings for both **width** and **height** of the profile.
* **Stone Setting**:\
  In the **Stone Setting** area, you can choose to add gemstones to the ring and select the type of **setting** you wish to apply. The options for gemstone distribution are:
  * **Full**
  * **Half**
  * **One Quarter**
  * **Custom** (If selected, you'll define how many gemstones to add and whether you want them to be evenly spaced around the ring or grouped together in a continuous pattern.)
* **Gemstone Customization**:\
  Within the **Custom** setting, you can define additional parameters such as:
  * **Gem Size**
  * **Minimum Distance** between the gems
  * **Z-Axis Displacement**, allowing you to control how the gemstones are positioned along the height of the ring.

This command provides an intuitive way to create personalized wedding rings, offering both precise customization for the profile and size, as well as flexible options for adding and arranging gemstones.
