# Splop

### <img src="../../../../.gitbook/assets/G9_06_TRANSFORMATION_SPLOP.png" alt="" data-size="line"> Splop <a href="#profiles" id="profiles"></a>

The **Splop** command copies, rotates, scales, and wraps objects onto a surface, similar to adding decorative elements to pottery.

### Steps:

1. Select the objects to wrap.
2. Draw a reference sphere around the objects to determine their size and orientation.
3. Select a surface onto which the objects will be wrapped.
4. Pick a point on the surface and drag out a sphere to position the objects.

### Command-Line Options:

* **Copy**: Creates a copy of the objects when wrapping them onto the surface.
* **Rigid**: Moves objects without deforming them if set to "Yes." If "No," objects are deformed during the transformation.
* **Flip**: Reverses the direction in which the objects are applied to the surface.

These options allow for versatile manipulation and placement of objects onto surfaces, providing creative control over their final appearance.



For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/splop.htm#\(null\)).
