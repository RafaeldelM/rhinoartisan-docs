# Twist

### <img src="../../../../.gitbook/assets/G9_09_TRANSFORMATION_TWIST.png" alt="" data-size="line"> Twist <a href="#profiles" id="profiles"></a>

The **Twist** command deforms objects by rotating them around a specified axis. To use it, select the objects, define the start and end points of the twist axis, and set the rotation angle either by typing or by picking two reference points.

Command-line options:

* **Copy**: Creates a copy of the objects when twisting.
* **Rigid**: Transforms object positions without deforming them.
* **Infinite**: Applies twisting throughout the entire object or limits it to the length of the axis.
* **PreserveStructure**: Maintains the control-point structure of curves and surfaces for precision.

These options allow for flexible twisting and precise deformation of objects.



For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/twist.htm#\(null\)).
