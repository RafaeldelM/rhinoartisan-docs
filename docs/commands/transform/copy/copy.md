# Copy

### <img src="../../../.gitbook/assets/G2_01_TRANSFORMATION_COPY.png" alt="" data-size="line"> Copy <a href="#profiles" id="profiles"></a>

Using this command you can create a custom Element following a curve, and use multiple shapes on multiple points along the curve. Ideal to make decorative elements, or sleek and amazing jewelry pieces.



For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/copy.htm#\(null\)).
