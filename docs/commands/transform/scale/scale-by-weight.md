# Scale By Weight

## ​<img src="../../../.gitbook/assets/G4_01_TRANSFORMATION_SCALE_BY_WEIGHT.png" alt="" data-size="line"> Scale by Weight <a href="#scale-by-weight" id="scale-by-weight"></a>

This command allows us to scale objects by their weight. It works straightforwardly yet powerfully. We select the objects, and the current weight is shown. Then, we can input the desired weight, and it calculates it instantly.
