# Sel Controls

### <img src="../../../.gitbook/assets/G10_04_TRANSFORMATION_CAGE_CONTROLS.png" alt="" data-size="line"> Sel Controls <a href="#profiles" id="profiles"></a>

The SelControls command selects cage control objects set up using the **CageEdit** command.



For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/selection_commands.htm#SelControls).
