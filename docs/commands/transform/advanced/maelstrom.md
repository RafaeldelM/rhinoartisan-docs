# Maelstrom

### <img src="../../../.gitbook/assets/G10_01_TRANSFORMATION_MAELSTORM.png" alt="" data-size="line"> Maelstrom <a href="#profiles" id="profiles"></a>

The **Maelstrom** command deforms objects by twisting them into a spiral pattern, creating a vortex-like effect.

#### Key Steps:

1. Select the objects to deform.
2. Choose the center point of the maelstrom and specify the first radius.
3. Set the second radius for the spiral deformation.
4. Define the coil angle to determine the spiral’s tightness and direction.

#### Command-Line Options:

* **Copy**: Creates a copy of the objects when applying the spiral deformation.
* **Rigid**: If set to "Yes," moves objects without deforming them. If set to "No," both the positions and shapes of the objects are transformed.

These options provide control over how the objects are spiraled, allowing for creative and dynamic deformations.



For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/maelstrom.htm#\(null\)).
