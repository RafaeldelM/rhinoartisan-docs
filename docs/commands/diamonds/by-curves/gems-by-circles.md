# Gems by Circles



### <img src="../../../.gitbook/assets/G2_04_DIAMONDS_GEM_FROM_CURVE (1).png" alt="" data-size="line"> Gems by Circles

The **Gems by Circles** command is a simple yet powerful tool for placing round gemstones precisely. It uses the circles you select in your design to automatically position gemstones with the same diameter and on the same plane.

<figure><img src="../../../.gitbook/assets/Arracada Victor 2.3dm (22 MB) - Artisan (read-only) - [Perspective] 04_09_2024 15_06_20.png" alt=""><figcaption></figcaption></figure>

1. **Select Circles**: Choose the circles in your design where you want the gemstones to be placed. These circles will serve as guides for gem placement.
2. **Automatic Placement**:
   * **Consistent Size**: The gemstones will match the diameter of the selected circles.
   * **Aligned Plane**: Gems are placed on the same plane as the circles, ensuring perfect alignment.

:::info
Goldsmith Tip : This can be very useful for those pieces that needs the Quick Flow on Srf tool. We can distribute the circles in a plane surface, then flow them in a complex curved surface and once we are satisfied with the circles distribution put the gems in a single click.
:::
