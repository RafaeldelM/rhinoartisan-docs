# Gem Creator

## <img src="../../.gitbook/assets/G1_03_DIAMOND_CREATOR.png" alt="" data-size="line"> Gem Creator

The **Custom Gemstone** command allows you to create a gemstone directly from a planar curve, using that curve as the stone's girdle. Once the girdle is defined, you can easily control key parameters, including the table, crown, girdle thickness, pavilion, and culet.&#x20;

This tool offers the flexibility to craft a fully customized gemstone from a simple planar curve, easily enabling precise and unique designs.

<figure><img src="../../.gitbook/assets/Gem Creator.jpg" alt=""><figcaption></figcaption></figure>

:::info
**Goldsmith Tip:** Use your mobile device to capture a top-view image of your stone or scan it with a document scanner if the base is flat. Import the image into the viewport and scale it to its actual size.&#x20;
:::

Use the curve command to trace the stone's silhouette. Finally, apply the **Gem Creator** command to accurately recreate the stone in your scene with just a few simple steps.
