# Pearl

## <img src="../../.gitbook/assets/G3_01_DIAMOND_PEARL.png" alt="" data-size="line"> Pearl <a href="#pearl" id="pearl"></a>

The Pearl command allows you to create a realistic 3D representation of a pearl, complete with a supporting calotte and a wire for mounting. This versatile tool is ideal for jewellers designing earrings, pendants, or other pieces featuring pearls.

<figure><img src="../../.gitbook/assets/Pearl.jpg" alt=""><figcaption></figcaption></figure>

### **Parameters**

* **Pearl Diameter:** Adjust the size of the pearl sphere.
* **Calotte Angle:** Determines the angle of the calotte, which is the curved base that supports the pearl. A higher angle creates a more pronounced curve, while a lower angle results in a flatter base.
* **Wire Length:** This setting sets the length of the wire, which can be used as a post for earrings or other mounting purposes.
* **Wire Diameter:** Specifies the thickness of the wire.

### **Usage**

**Adjust parameters:** Use the software's controls or input fields to modify the pearl's diameter, calotte angle and thickness, wire length, and wire diameter.

:::info
Goldsmith Tip: To attach a twisted wire to the Calotte, use the RhinoArtisan Rope command.&#x20;
:::
