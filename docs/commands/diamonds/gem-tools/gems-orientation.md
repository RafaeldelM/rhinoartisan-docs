# Gems Orientation

## <img src="../../../.gitbook/assets/G6_01_DIAMOND_SHOW_ORIENTATION.png" alt="" data-size="line"> Gems Orientation

This command allows us to view each gem's individual alignment and rotate them as we wish. It's especially useful when the gems aren't aligned the way we'd like them to be for applying gem sets.

<figure><img src="../../../.gitbook/assets/Gem Orientation.jpg" alt=""><figcaption></figcaption></figure>

Above each gem, the plane and an edit button (pencil icon) will be displayed. Clicking the button will change the alignment. We can repeat the process as many times as needed.
