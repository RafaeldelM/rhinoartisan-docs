# Gems Offset

## <img src="../../../.gitbook/assets/G6_11_DIAMOND_GEM_OFFSET_CRV.png" alt="" data-size="line"> Gems Offset

This command extracts the girdle curve and applies an offset of one or more gems.&#x20;

<figure><img src="../../../.gitbook/assets/image (638).png" alt=""><figcaption><p>Gems Offset</p></figcaption></figure>

1. Select one or more gems.
2. Set the offset value; this parameter can be negative.
