# Solid Control Points

## <img src="../../.gitbook/assets/G0_02_SOLID_SOLID_POINTS.png" alt="" data-size="line"> Solid Control Points <a href="#profiles" id="profiles"></a>

The SolidPtOn command turns on grips at the ends of surface and joined polysurface edges, including closed solids.



For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/mesh.htm).
