# Boolean Union

### <img src="../../../.gitbook/assets/G5_01_SOLID_BOOLEAN_UNION.png" alt="" data-size="line"> Boolean Union

The BooleanUnion command trims the shared areas of selected polysurfaces or surfaces and creates a single polysurface from the unshared areas.

**Steps**

* Select the objects and press Enter.\
  The objects combine into one polysurface.



For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/mesh.htm).
