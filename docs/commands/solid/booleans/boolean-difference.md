# Boolean Difference

<img src="../../../.gitbook/assets/G5_02_SOLID_BOOLEAN_DIFFERENCE.png" alt="" data-size="line"> Boolean Difference

The BooleanDifference command trims the shared areas of selected polysurfaces or surfaces with another set of polysurfaces or surfaces.

**Steps**

1. Select surfaces or polysurfaces to subtract from, and press Enter.<br>
2. Select surfaces or polysurfaces to subtract with, and press Enter.



For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/mesh.htm).
