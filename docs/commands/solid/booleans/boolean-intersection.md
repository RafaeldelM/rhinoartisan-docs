# Boolean Intersection

<img src="../../../.gitbook/assets/G5_03_SOLID_BOOLEAN_INTERSECTION.png" alt="" data-size="line"> Boolean Intersection

The BooleanIntersection command trims the unshared areas of selected polysurfaces or surfaces.

**Steps**

1. Select the first set of objects or a set of intersecting objects and press Enter.<br>
2. If a first set of objects was selected, select the second set of objects and press Enter.



For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/mesh.htm).
