# Clipboard Functions

### <img src="../../.gitbook/assets/FILE_COPY.png" alt="" data-size="line"> Copy

The Copy command makes duplicates of the selected objects.

### <img src="../../.gitbook/assets/FILE_CUT.png" alt="" data-size="line"> Cut

The Cut command deletes objects from the model and places them in the Clipboard.

### <img src="../../.gitbook/assets/FILE_PASTE.png" alt="" data-size="line"> Paste

The Paste command inserts objects from the Clipboard.

### <img src="../../.gitbook/assets/FILE_UNDO.png" alt="" data-size="line"> Undo

The Undo command reverses recent changes to objects.

### <img src="../../.gitbook/assets/FILE_UNDO_SELECTED.png" alt="" data-size="line"> Undo Selected

The UndoSelected command reverses recent changes for a selected object only.

### <img src="../../.gitbook/assets/FILE_UNDO_MULTIPLE.png" alt="" data-size="line"> Undo Multiple

The UndoMultiple command displays a list of recent commands to reverse.

### <img src="../../.gitbook/assets/FILE_REDO.png" alt="" data-size="line"> Redo

The Redo command steps back through geometry changes activated by the Undo command
