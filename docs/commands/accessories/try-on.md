# Try On

## &#x20;<img src="../../.gitbook/assets/Group 4.png" alt="" data-size="line"> Try On

The **Try On** command in RhinoArtisan allows users to simulate a hand in the viewport to visualize how the designed ring would look when worn. This command is particularly useful for providing a realistic perspective on the design's proportions, style, and aesthetics.

<figure><img src="../../.gitbook/assets/image (713).png" alt=""><figcaption></figcaption></figure>

#### Key Features of the **Try On** Command:

* **Hand Type Selection**: Choose between a male or female hand to match the target audience of the design.
* **Hand Orientation**: Select either a left or right hand for flexible visualization of the ring.
* **Skin Tones**: Offers a choice of 6 different skin tones, ensuring an inclusive representation of diverse tones.

Once the command is activated, the designed ring is automatically placed on the selected hand's ring finger, aligning precisely for a realistic presentation.
