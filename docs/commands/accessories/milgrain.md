# Milgrain

## <img src="../../.gitbook/assets/RIBBON_SMART_MILGRAIN.png" alt="" data-size="line"> Milgrain <a href="#milgrain" id="milgrain"></a>

With this command, you can generate milgrain running down a selected curve. This is especially useful for adding a vintage touch to any design.

![](/img/v60/Milgrain.jpg)

The usage is simple: we'll start by selecting one or more curves.

On its parameters, you can change the diameter of each sphere, the overlapping distance in millimetres between spheres, and whether you want it to start and end within the curve's limits or at the very end.

:::tip
This element is editable, meaning it can be modified anytime.
:::
