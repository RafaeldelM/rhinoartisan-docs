# Insert Point

## <img src="../../../.gitbook/assets/INSERT_POINT.png" alt="" data-size="line"> Insert Point <a href="#profiles" id="profiles"></a>

The InsertPoint command adds vertices and edges to a Mesh or SubD along the picked points on edges.

<div align="left"><img src="https://docs.mcneel.com/rhino/8/help/en-us/image/topic_illustrations/insertpoint.gif" alt=""></div>

### Input

* SubD / Mesh Edge

### **Steps**

1. Select a mesh or SubD.
2. Pick points on edges.

### Options

**Undo:** Removes the last picked point.
