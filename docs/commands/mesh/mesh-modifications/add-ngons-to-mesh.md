# Add Ngons To Mesh

## <img src="../../../.gitbook/assets/ADD_NGONS_TO_MESH.png" alt="" data-size="line"> Add Ngons To Mesh <a href="#profiles" id="profiles"></a>

The AddNgonsToMesh command converts regions of connected coplanar welded mesh faces into [Ngons](https://docs.mcneel.com/rhino/8/help/en-us/popup_moreinformation/ngon.htm).

![](https://docs.mcneel.com/rhino/8/help/en-us/image/topic_illustrations/addngonstomesh.gif)<br>

Note: This command does not allow selecting meshes in a block. To select meshes in a block, use the [BlockEdit](https://docs.mcneel.com/rhino/8/help/en-us/commands/block.htm#BlockEdit) command to edit the block first.
