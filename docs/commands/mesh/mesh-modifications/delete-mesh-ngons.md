# Delete Mesh Ngons

## <img src="../../../.gitbook/assets/DELETE_MESH_NGONS.png" alt="" data-size="line"> Delete Mesh Ngons <a href="#profiles" id="profiles"></a>

The DeleteMeshNgons command converts [Ngons](https://docs.mcneel.com/rhino/8/help/en-us/popup_moreinformation/ngon.htm) on a mesh into triangle or quad faces.

![](https://docs.mcneel.com/rhino/8/help/en-us/image/topic_illustrations/deletemeshngons.gif)<br>

Note: This command does not allow selecting meshes in a block. To select meshes in a block, use the [BlockEdit](https://docs.mcneel.com/rhino/8/help/en-us/commands/block.htm#BlockEdit) command to edit the block first.
