# Generate Dimensions By Box

<img src="../../.gitbook/assets/DRAFTING_GENERATE_DIMENSIONS_BOX.png" alt="" data-size="line"> **Generate Dimensions by Box** is a one-click tool that extracts and displays the main overall dimensions of any object by using its bounding box. It provides the width, length, and height of the selected geometry, regardless of the type of jewel or object.

It’s especially useful when you need to quickly understand the size of a piece for presentation, packaging, or volume estimation, without requiring specific structural data.
