# Breakdown Extras

### <img src="../../.gitbook/assets/BREAKDOWN_EXTRA.png" alt="" data-size="line"> Breakdown Extras

:::info
Available in the 6.2 update
:::



When activating the **Breakdown Extras** command, it generates a text output that can be placed anywhere in the **viewport**, displaying the extra process details contained in the **Breakdown Details**.

<figure><img src="../../.gitbook/assets/image (737).png" alt=""><figcaption></figcaption></figure>

**Advantages:**

* Instantly displays extra process details in the viewport.
* Allows flexible placement of information within the design.
* Speeds up workflow by eliminating manual documentation.
