# Breakdown Metals

### <img src="../../.gitbook/assets/BREAKDOWN_METALS.png" alt="" data-size="line"> Breakdown Metals

:::info
Available in the 6.2 update
:::

When activating the **Breakdown Metals** command, it generates a text output that can be placed anywhere in the **viewport**, displaying the metal details contained in the **Breakdown Details**.

<figure><img src="../../.gitbook/assets/image (738).png" alt=""><figcaption></figcaption></figure>

**Advantages:**

* Instantly displays metal details in the viewport.
* Ensures accuracy by following the **Outliner** configuration.
* Allows flexible placement of information within the design.
