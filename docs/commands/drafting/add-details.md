# Add Details

## <img src="../../.gitbook/assets/03_DRAFTING_DETAIL.png" alt="" data-size="line"> Add Details

The Detail command manages layout detail viewports, which are modelling viewports that can be placed on a layout viewport.

<figure><img src="../../.gitbook/assets/image (562).png" alt=""><figcaption></figcaption></figure>

By default, RhinoArtisan creates the four main views of our model, but in some cases, additional detail views might be useful to highlight specific parts.

For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/detail.htm#\(null\)).
