# Rectangular int Light

### <img src="../../../.gitbook/assets/SPOTLIGHT_03_RENDERING_RECTANGULAR_LIGHT.png" alt="" data-size="line"> Rectangular int Light

The RectangularLight command inserts a rectangular light object that emits light from an array of light points in one direction.

<figure><img src="../../../.gitbook/assets/rectangularlight-001.png" alt=""><figcaption></figcaption></figure>

Command-line option

**Target**

Aims the light at the specified location.



For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/lights.htm#RectangularLight).
