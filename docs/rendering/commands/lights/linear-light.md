# Linear Light

### <img src="../../../.gitbook/assets/SPOTLIGHT_04_RENDERING_LINEAR_LIGHT.png" alt="" data-size="line"> Linear Light

The LinearLight command inserts a light that imitates a fluorescent tube.

**Steps**

1. Pick the start of the light.
2. Pick the end of the light.



For more information, please refer to the [Rhino documentation](https://docs.mcneel.com/rhino/8/help/en-us/commands/lights.htm#LinearLight).
